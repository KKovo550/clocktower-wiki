# 钟楼资料库

一个面向《染·钟楼谜团》（Blood on the Clocktower）玩家与说书人的中文资料网站，整合角色百科、规则查询、剧本库和剧本编辑工具，支持电脑与手机浏览。

**[在线访问网站](https://kkovo550.github.io/clocktower-wiki/)** · **[反馈问题](https://github.com/KKovo550/clocktower-wiki/issues)**

> 本项目为个人整理的非官方网站，与游戏发行方、原百科及素材作者不存在官方隶属或授权合作声明。本仓库保存用于 GitHub Pages 的静态发布文件。

## 可以做什么

### 查找角色与规则

- **全站搜索**：按标题、别名和正文查找资料；按 `/` 快速聚焦搜索框。
- **全角色索引**：目前包含 456 个角色条目，支持名称、ID、技能描述、角色类型和能力类别筛选。
- **海外自制角色**：收录 126 个公开角色，提供图标网格、中英文名称搜索、能力描述与原文链接；与官方角色区分展示。
- **相克规则**：以角色图标和组合卡片呈现，支持关键词搜索，并区分相克规则、建议组合和华灯初上相关规则。
- **夜晚行动顺序**：支持首夜、其他夜晚切换及并排对照；按角色名或行动说明查询，筛选后保留原表编号。
- **认证说书人查询**：按姓名、编号、等级和名单分组查阅收录记录。

### 查找与编写剧本

- **剧本库**：浏览与筛选剧本，按包含或排除角色查找，支持对比、收藏和 JSON 导出。
- **剧本工具**：选择角色、添加自定义角色、编辑剧本信息、查看夜序、导入和导出 JSON。
- **海外自制角色接入**：在剧本工具中搜索角色中文名、英文名或“海外自制”即可查找并添加。
- **剧本检查**：检查重复角色 ID、无效阵营及部分设置、相克提示；缺少资料时提示核对。
- **跨页面操作**：已匹配的角色详情可查找相关剧本；剧本库中的可用 JSON 可发送到编辑器，确认载入后继续修改。

## 开始使用

### 在线浏览

打开 **https://kkovo550.github.io/clocktower-wiki/** 即可使用，无需登录 GitHub。也可以直接将网址分享给朋友，使用手机浏览器打开。

界面适配不同屏幕尺寸，轻量动画遵循系统的“减少动态效果”设置。

### 下载后离线使用

1. 在仓库页面选择 **Code → Download ZIP**。
2. 完整解压，保留所有文件及目录结构。
3. 在电脑浏览器中打开 `index.html`。

静态页面、已包含的图标、搜索数据和主要工具可离线使用；来源网站等外部链接需要联网。手机本地文件访问受浏览器和系统限制，建议手机使用在线网址。

### 保存剧本

编辑器会尝试将草稿保存在当前浏览器中。浏览器数据不是云端备份：更换设备、切换浏览器、清理站点数据或使用隐私模式，都可能无法恢复原草稿。

**重要剧本请及时导出 JSON。** 在线网址与本地文件的浏览器存储也不应视为互通。

## 关于图片

**当前公开网站和本仓库不包含剧本图片库。**

- 角色图标、百科页面使用的图片仍然保留。
- 剧本库的文字资料、角色列表以及可用的 JSON 查询和导出不受此项限制。
- 剧本图片预览和图片导出在当前发布版中不可用。
- 暂未接入阿里云 OSS 或其他外部剧本图片存储。

这是当前发布策略，避免将大型原图资源库一并上传到 GitHub Pages。

## 数据与规则说明

- 本站是收录资料的静态快照，不会在访问时自动拉取原站更新。
- 角色类型、能力类别、技能关键词是不同的筛选维度；关键词标签不能替代完整规则解释。
- “未归类”表示当前分类资料未覆盖，不代表该角色不具备相关能力。
- 海外自制角色与官方角色可能同名，请结合英文名、来源标识与详情页辨别。
- 海外自制角色缺少可用的原始 JSON 时，夜序、提醒标记和设置调整需要人工核对；工具提示不能替代说书人判断。
- 夜序页保留原文推荐顺序和调整说明，不自动推断特殊角色互动。
- 认证名单仅反映本地收录资料，认证变更请结合相关公示和原始来源核对。

## 网站如何更新

本仓库通过 **GitHub Pages** 发布，发布来源为 `main` 分支根目录，使用 `.nojekyll` 直接提供静态文件。

维护流程：

1. 在本地维护项目中修改内容并完成构建、检查。
2. 将新的静态发布文件同步到本仓库，继续排除剧本图片库、凭据和本机缓存。
3. 提交并推送到 `main`。
4. 在仓库的 **Actions** 中确认 Pages 部署成功，再检查线上页面。

**只修改电脑里的文件，不会自动更新公开网站。** 推送并部署成功后，网站地址保持不变；如仍看到旧内容，可尝试强制刷新。

此仓库是发布产物仓库，不包含完整的 Python 构建、采集和同步脚本；浏览本站无需安装 Python、Node.js 或其他开发环境。

```text

├── index.html          # 网站首页
├── allpages.html       # 全部页面

├── files.html          # 图片列表
├── stats.html          # 统计页面
├── pages/              # 角色、规则及其他百科正文
├── files/              # 图片详情页面
├── assets/             # 共享样式、交互脚本、搜索索引与媒体
├── role_index/         # 全角色索引页面
├── script_lib/         # 剧本库页面与内置数据
├── script_tool/        # 剧本编辑工具及角色图标
└── .nojekyll           # GitHub Pages 静态发布标记
```
