# 钟楼资料库

查角色、找剧本、做海报，用魔典带团与复盘。面向《染·钟楼谜团》（Blood on the Clocktower）玩家与说书人的中文资料网站，支持电脑与手机。

**[打开网站](https://kkovo550.github.io/clocktower-wiki/)** · [使用指南](docs/USER_GUIDE.md) · [魔典教程](https://kkovo550.github.io/clocktower-wiki/index.html#guide-grimoire) · [反馈问题](https://github.com/KKovo550/clocktower-wiki/issues)

本仓库存放 GitHub Pages 的**静态发布文件**，浏览网站无需安装开发环境。源码项目的安装与维护步骤见[开发说明](DEVELOPMENT.md)。

## 快速入口

- [角色百科](https://kkovo550.github.io/clocktower-wiki/role_index/角色索引.html)：搜索名称、ID、能力与来源。
- [剧本库](https://kkovo550.github.io/clocktower-wiki/script_lib/剧本库.html)：找剧本、看角色搭配、收藏与对比。
- [剧本工具](https://kkovo550.github.io/clocktower-wiki/script_tool/剧本工具.html)：编写剧本、导入 JSON、制作海报。
- [在线魔典](https://kkovo550.github.io/clocktower-wiki/script_tool/在线魔典.html)：开局、管理身份与状态、记录并分享复盘。
- [夜序查看器](https://kkovo550.github.io/clocktower-wiki/script_tool/夜序查看器.html)：单独管理在场玩家与夜间行动。
- [相克规则](https://kkovo550.github.io/clocktower-wiki/pages/相克规则.html) · [夜晚行动顺序](https://kkovo550.github.io/clocktower-wiki/pages/夜晚行动顺序一览.html) · [认证说书人查询](https://kkovo550.github.io/clocktower-wiki/pages/认证说书人查询.html)。

## 可以做什么

### 查资料、找剧本

按角色名称、类型、能力类别和来源组合查询。角色合集包含官方、华灯初上、山雨欲来、奥德赛、群星与海外自制等资料；同名角色需结合来源与能力版本辨别。

剧本库支持名称与作者搜索、包含／排除角色、分类筛选、相似剧本对比、个人收藏及可用 JSON 导出。角色与剧本详情保留对应的资料入口，方便继续查阅。

### 编辑剧本、生成图片

从预设、JSON 或图片识别开始，添加角色、修改本局能力与夜序，保存草稿和恢复点。图片识别在浏览器运行，识别结果需核对角色名称、来源和遗漏项。

制图支持 Logo、背景、夜序、相克与排版调整，导出 PNG／SVG。默认智能适配，优先保留 1111 × 1500，内容过多时按原双栏风格加长；也可手动选择严格固定尺寸。详细步骤见[剧本工具说明](docs/SCRIPT_TOOL.md)。

### 用魔典带团、记录与分享

- 管理座位、角色、夜序、提醒、生死与死亡票，支持线下轮流抽取、计时、私密笔记与玩家视角。
- 手机 15 人圆桌使用顶部快捷工具栏，座位标签显示编号与姓名；小屏或标记较多时可滑动查看。
- 在玩家详情点击“添加复盘记录”，直接填写该玩家当前阶段的行动。记录以本局 JSON 为依据，能识别的要求生成对应字段，复杂条件由说书人核对并补充实际结果。
- 查看阶段变化与魔典快照，导出图片或离线互动 HTML，也可预览后生成手机只读分享链接。
- 对局库支持保存与归档，重要对局可下载备份后恢复。

复盘中的点击定位显示阶段快照。行动表单帮助记录，能力是否生效仍由说书人决定。详见[魔典说明](docs/GRIMOIRE.md)。

## 第一次使用

首页的“使用指南”提供五条路线：**查角色、找剧本、做剧本、带夜序、用魔典**。

- 想看规则：进入角色百科，搜索名字或能力词，再阅读详情中的范例与运作方式。
- 想做剧本：加载一个预设，调整角色，导出 JSON，再生成图片。
- 想带团：打开魔典，选择剧本和人数，分配角色，按昼夜推进并记录行动。

手机支持抽屉导航和触屏操作，网页采用暖纸与深色页头主题。无需注册即可使用主要静态工具。

## 保存和分享前要知道

- 草稿、笔记、收藏和对局主要保存在当前浏览器，不会自动跨设备同步。换设备或清理网站数据前，请先导出对应备份。
- 剧本 JSON 用于交换角色与夜序；完整创作备份用于迁移编辑资料；对局备份用于继续魔典。图片与只读复盘无法还原全部编辑状态。
- 只读复盘是固定快照，之后修改不会同步。分享包含所选阶段的真实身份、夜间信息与提醒，不包含玩家私密笔记和未保存草稿；发送前核对预览。
- 手机只读链接需要分享服务联网可用；离线互动 HTML 与已导出的图片可独立阅读。服务配置与限制见[魔典说明](docs/GRIMOIRE.md)。

## 离线使用

下载本仓库 ZIP 或维护者提供的离线分享包，完整解压并保留目录结构，在电脑浏览器中打开 `index.html`。

已包含的页面、图标、搜索数据与主要工具可离线使用。外部链接、未内嵌的远程图片、在线编辑和手机只读分享需要联网。手机本地文件访问受系统限制，优先使用在线网址。

公开版包含剧本的压缩预览，**不包含原尺寸剧本图片库**。角色名单、可用 JSON 查询与编辑制图功能保留。

## 网站如何更新

网站由源码项目通过 Astro 构建，再将静态产物发布到本仓库。**本地修改或构建不会自动更新公开网站**；推送发布文件并完成 GitHub Pages 部署后，线上内容才会变化。

此仓库不包含完整开发环境。需要参与开发时，请按[开发说明](DEVELOPMENT.md)和[协作指南](docs/COLLABORATION.md)使用完整源码项目。网站显示旧内容时先确认是否已经部署，再尝试刷新，不要直接清理保存资料的浏览器存储。
