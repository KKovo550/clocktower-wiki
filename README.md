# 钟楼资料库

一个面向《染·钟楼谜团》（Blood on the Clocktower）玩家与说书人的中文资料网站，整合角色百科、规则查询、剧本库和剧本编辑工具，支持电脑与手机浏览。

**[在线访问网站](https://kkovo550.github.io/clocktower-wiki/)** · **[反馈问题](https://github.com/KKovo550/clocktower-wiki/issues)** · **[文档中心](docs/README.md)**

> 本项目为个人整理的非官方网站，与游戏发行方、原百科及素材作者不存在官方隶属或授权合作声明。本仓库保存用于 GitHub Pages 的静态发布文件。

网站使用 **Astro** 生成静态页面，保留原有页面地址和离线使用能力。角色资料整理、同步与图片处理仍由 Python 内容管线负责；搜索和剧本工具在浏览器内运行。本仓库是构建后的发布内容，Astro 源码与维护脚本保存在本地维护项目中。

## 可以做什么

### 查找角色与规则

- **全站搜索**：按标题、别名和正文查找资料；按 `/` 快速聚焦搜索框。
- **全角色索引**：支持名称、ID、技能描述、角色类型、能力类别及剧本来源筛选。来源可多选，包括暗流涌动、黯月初升、梦殒春宵、华灯初上、山雨欲来、奥德赛、实验性角色和海外自制角色。
- **角色总览**：奥德赛、群星与海外自制页面统一按角色类型展示图标网格和目录；点击图标进入对应详情，同名角色按来源区分。
- **悬浮预览**：鼠标停留在支持预览的角色图标上，显示中文名、已有英文名、角色类型、能力及已有背景故事。点击仍直接跳转详情页；支持淡入淡出和系统减少动态效果设置。
- **相克规则**：以角色图标和组合卡片呈现，支持关键词搜索，并区分相克规则、建议组合、华灯初上及奥德赛相关规则。
- **夜晚行动顺序**：支持首夜、其他夜晚切换及并排对照；按角色名或行动说明查询，筛选后保留原表编号；包含根据前位角色合并的奥德赛行动。
- **认证说书人查询**：按姓名、编号、等级和名单分组查阅收录记录。

### 查找与编写剧本

- **剧本库**：浏览与筛选剧本，按包含或排除角色查找，支持对比、收藏和 JSON 导出。
- **剧本工具**：选择角色、添加自定义角色、编辑剧本信息、导入和导出 JSON；首夜与其他夜晚可独立拖拽调整，结果用于制图和 JSON 导出。
- **图片导入**：上传剧本图片，先识别标题并查找剧本库中的候选记录，再识别和匹配角色；核对结果、补选遗漏角色后导入编辑器。默认 PaddleOCR 在浏览器内运行，无需自己启动服务，可切换试验性 GPU 加速或兼容识别引擎。
- **在场夜序**：独立夜序查看器支持导入 JSON、手动添加玩家并分配角色，仅显示在场角色的首夜和其他夜晚行动顺序。
- **剧本制图**：在剧本工具中点击“生成剧本图片”，默认浅白纸纹，支持海报或简洁分栏、参考图比例或自动加长。提供十二种标题 Logo 预设，也可上传自己或 AI 制作的 Logo，调整字号、配色和背景，下载完整单张 PNG 或 SVG。海报显示两侧夜序及相克说明，支持编辑角色说明、交换同类角色、撤销和重做。图片在本机处理，未接入 AI 生成服务。
- **自定义相克**：在制图界面选择两个角色并填写规则，可修改、删除并保存到当前浏览器；仅用于该角色组合的图片，不修改全站规则或剧本 JSON。
- **海外自制角色接入**：在剧本工具中搜索角色中文名、英文名或“海外自制”即可查找并添加。
- **角色图标**：已匹配的收录角色导出 JSON 时使用本站统一 HTTPS 图床；制图仍优先使用本地资源，未匹配的自定义角色保留原图片信息。
- **剧本检查**：检查重复角色 ID、无效阵营及部分设置、相克提示；缺少资料时提示核对。
- **跨页面操作**：已匹配的角色详情可查找相关剧本；剧本库中的可用 JSON 可发送到编辑器，确认载入后继续修改。

## 开始使用

### 在线浏览

打开 **https://kkovo550.github.io/clocktower-wiki/** 即可使用，无需登录 GitHub。也可以直接将网址分享给朋友，使用手机浏览器打开。

手机端保留原蓝白配色，采用顶部快捷导航和左侧抽屉菜单，保留当前页面高亮；角色总览使用两列图标。菜单支持点击遮罩关闭，轻量动画遵循系统的“减少动态效果”设置。

### 下载后离线使用

1. 在仓库页面选择 **Code → Download ZIP**。
2. 完整解压，保留所有文件及目录结构。
3. 在电脑浏览器中打开 `index.html`。

静态页面、已包含的图标、搜索数据和主要工具可离线使用；来源网站等外部链接需要联网。手机本地文件访问受浏览器和系统限制，建议手机使用在线网址。

### 图片识别

在剧本工具中打开“从图片导入剧本”，选择图片和排版后开始识别。标题或角色匹配结果需要人工确认；库中找到同名剧本也要核对作者和版本。OCR 提取文字并匹配本站角色库，不会自动理解全部规则、夜序、相克或海报装饰。能力和默认夜序来自当前角色库。

首次使用需要载入较大的模型和运行资源，耗时与设备、网络有关；在线使用会从本站下载资源，完整离线包从本地载入。默认兼容 CPU 模式，GPU 加速为试验选项，失败时会回退。识别过程中可关闭窗口取消；不要反复开多个识别页面。详见[图片导入说明](docs/SCRIPT_TOOL.md#从图片导入剧本)。

### 保存剧本

编辑器会尝试将草稿保存在当前浏览器中。浏览器数据不是云端备份：更换设备、切换浏览器、清理站点数据或使用隐私模式，都可能无法恢复原草稿。

**重要剧本请及时导出 JSON。** 在线网址与本地文件的浏览器存储也不应视为互通。

草稿先完整校验再恢复，损坏数据不会被自动覆盖。旧草稿中带名称的“戏子（改）”会迁移到独立 ID，并保留手动夜序；仅含旧共享 ID 的 JSON 需要重新选择改版角色。

图片中的说明与角色排版独立于剧本 JSON。重新打开制图会读取当前夜序，以及主界面已修改的标题、作者；图片撤销操作不会回滚主剧本夜序。

## 编写与制图的推荐步骤

1. 在剧本工具中选择角色，或导入已有 JSON；从剧本库发送过来的内容需要确认载入。
2. 填写剧本名和作者，查看搭配检查，核对角色来源、设置调整与相克。
3. 打开夜序窗口，分别调整首夜和其他夜晚；需要重来时恢复默认夜序。
4. 导出 JSON 保存剧本，再打开“生成剧本图片”。
5. 选择版式与比例，编辑图片说明、特殊规则和自定义相克，预览后下载 PNG 或 SVG。

JSON 保存角色与夜序等剧本数据；图片中的文字编辑、排版及自定义相克不会全部写回 JSON。请分别保留需要的文件。

## 常见问题

### 网站更新后仍显示旧内容

可以先强制刷新或重新打开页面。不要为了刷新而清理站点数据，否则可能丢失草稿和个人记录。

### 草稿为什么没有同步到另一台设备

草稿存放在当前浏览器，不会自动上传云端。迁移剧本请导出并导入 JSON；剧本库个人记录使用其备份与恢复功能。JSON 不包含全部制图编辑状态。

### 夜序或相克与预期不同

先核对角色来源与版本，检查是否存在手动夜序。相克需要两个对应角色都被选中，制图还需要开启相克显示；同名但无法唯一匹配的角色不会自动应用规则。可通过角色详情的来源链接核对原文。

### 已收录的角色为什么显示文字占位

工具优先匹配本地图标，角色 ID 或图片地址不同也可按名称、类型等信息查找；同名存在歧义时不会猜选。仍缺图时检查角色来源与名称；远程地址失效或限制跨域读取，也会显示占位文字。

### 图中文字太密，或 PNG 无法下载

参考图比例会缩放内容；角色较多或说明较长时，将图片比例切换为“随内容自动加长”，再调整字号。下载时检查浏览器下载列表，也可降低 PNG 清晰度或改用 SVG。自定义远程图标缺失时会使用文字占位。

### 下载源码 ZIP 后能否运行 npm 命令

这个仓库保存构建好的网站，下载后可直接打开 `index.html`。完整开发工具和源码由维护项目管理，不包含在发布仓库中。

## 关于图片

**当前公开网站和本仓库不包含剧本图片库。**

- 角色图标、百科页面使用的图片仍然保留。
- 剧本库的文字资料、角色列表以及可用的 JSON 查询和导出不受此项限制。
- 剧本库原有剧照的预览和导出在当前发布版中不可用；剧本工具生成 PNG/SVG 不受影响。
- 暂未接入阿里云 OSS 或其他外部剧本图片存储。

这是当前发布策略，避免将大型原图资源库一并上传到 GitHub Pages。

## 数据与规则说明

- 本站是收录资料的静态快照，不会在访问时自动拉取原站更新。
- 角色类型、能力类别、技能关键词是不同的筛选维度；关键词标签不能替代完整规则解释。
- “未归类”表示当前分类资料未覆盖，不代表该角色不具备相关能力。
- 海外自制角色与官方角色可能同名，请结合英文名、来源标识与详情页辨别。
- 海外自制角色缺少可用的原始 JSON 时，夜序、提醒标记和设置调整需要人工核对；工具提示不能替代说书人判断。
- 夜序页保留收录的推荐顺序和调整说明，不自动推断特殊角色互动。待定位及表外角色保留导入夜序，已匹配但不行动的夜晚为 0；列表序号不等同于 JSON 夜序值。
- 相克提示、搭配检查和制图共用匹配逻辑，优先使用角色 ID；名称有歧义时不会自动匹配。
- 认证名单仅反映本地收录资料，认证变更请结合相关公示和原始来源核对。

## 程序调用

网站提供无需密钥的只读 JSON 接口。接口目录为 [api/v1/index.json](https://kkovo550.github.io/clocktower-wiki/api/v1/index.json)，角色、剧本索引、原始剧本 JSON、默认夜序和相克规则均可通过普通 HTTP GET 获取。搜索和筛选由调用方完成，接口不提供服务器 OCR 或上传功能。完整示例见[接口文档](docs/API.md)。

## 网站如何更新

本仓库通过 **GitHub Pages** 发布，发布来源为 `main` 分支根目录，使用 `.nojekyll` 直接提供静态文件。

维护流程：

1. 在本地维护项目中修改内容并完成构建、检查。
2. 将新的静态发布文件、README 和公开文档同步到本仓库，保留仓库配置及在线编辑记录，继续排除剧本图片库、凭据和本机缓存。
3. 提交并推送到 `main`。
4. 在仓库的 **Actions** 中确认 Pages 部署成功，再检查线上页面。

**只修改电脑里的文件，不会自动更新公开网站。** 推送并部署成功后，网站地址保持不变；如仍看到旧内容，可尝试强制刷新。

此仓库是发布产物仓库，不包含完整的 Python 构建、采集和同步脚本；浏览本站无需安装 Python、Node.js 或其他开发环境。
