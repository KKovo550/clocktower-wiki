使用指南

第一次来，从这里开始。

先选择你想做的事，按步骤开始操作；需要进一步了解时，展开每条路线下方的常见问题。

查角色找剧本做剧本带夜序

按名字或能力，找到角色。

适合查能力、理解规则，或按某种机制寻找角色。知道名字时直接搜索；只有一个想法时，从能力标签开始。

查找角色先读规则概要
  1. 打开角色百科并搜索点击“查找角色”，在搜索框输入中文名、角色 ID 或技能关键词。例如输入“复活”，寻找与复活有关的角色；输入多个词时，用空格分隔，结果需要同时包含这些词。
  2. 用能力与来源缩小范围点选获取信息、中毒、改变阵营、复活等快捷标签。需要限定官三、奥德赛等来源，或只看镇民、恶魔时，展开“高级筛选”。选中的条件会一起生效。
  3. 打开百科，先读能力再看范例点击角色名称进入详情。先看角色能力，再结合范例和运作方式理解触发时机；章节目录能直接跳到规则、夜序与技巧。各角色收录的章节可能不同。
  4. 沿着角色继续找剧本角色详情顶部有“查找包含此角色的剧本”入口，可以转到剧本库查看搭配。也可以从侧栏“角色合集”按资料片、角色类型浏览。
  5. 找不到时清除条件再试之前选择的标签和来源也会影响新搜索。点击“清除全部筛选”后重新输入名字；仍没有结果时，尝试中文名、英文 ID 或更短的能力关键词。
常见问题与操作提示
高级筛选里的“任一 / 全部”怎么理解？
能力类别多选默认满足其中任意一项；技能关键词可以切换为必须满足全部选中的词。不同筛选组之间则要同时满足，所以条件越多，结果通常越少。
为什么搜索能力词找不到某个角色？
技能关键词主要匹配能力文字，不等于全文规则搜索。把“搜索范围”改为“全部文本”，或取消来源、类型限制后再试；百科未收录的角色也可能没有结果。
只想学习规则，不知道从哪个角色开始？
点“先读规则概要”了解基本流程。侧栏“规则与入门 → 角色能力类别总览”能按获取信息、保护、提名等机制阅读解释和相关角色。

为下一场游戏，找到合适的剧本。

适合找板子、看角色搭配、收藏待玩的剧本，或把自己的设计与库内剧本对比。可以从名称、作者或想玩的角色开始。

浏览剧本库认识暗流涌动
  1. 搜索名称、作者或角色点击“浏览剧本库”，在“搜索剧本”中输入关键词。例如输入“#共情者”，精确查找包含共情者的剧本；普通关键词也可以搜索剧本名称与作者。多个关键词用空格分隔。
  2. 展开“更多筛选”在“必须包含的角色”中输入完整角色名，例如“洗衣妇、僧侣”，要求结果全部包含这些角色；“排除的角色”则去掉不想玩的角色。多个角色可用顿号、逗号或换行分隔。
  3. 结合分类和角色数量挑选按分类、包含阵营、最少 / 最多角色数继续筛选，也可勾选“只看有剧照”。这里的角色数是剧本名单的长度，不是当晚的玩家人数；适用人数还需结合剧本说明判断。
  4. 点击剧本，查看详情阅读作者、角色构成、剧照和个人记录。能打开百科的角色名称可以继续查看能力；点剧照可以放大。手机上查看完详情，可点“返回列表”继续挑选。
  5. 收藏、导出或继续编辑在“我的记录”中标记收藏、想玩、推荐或记录游玩，之后用“个人状态”筛选找回。需要文件时点“下载 JSON”或“复制 JSON”；想调整搭配，点“在剧本工具中编辑”。
  6. 用自己的剧本找相似搭配点顶部“对比我的剧本”，拖入或选择剧本 JSON。结果按角色重合情况比较，可查看相似度和共有角色；相似并不等于玩法、难度或平衡程度相同。
常见问题与操作提示
没有结果，或者结果太少怎么办？
点击“清除筛选”重新开始，先只搜一个名称或角色，再逐步增加条件。名称搜索、包含 / 排除角色、分类与个人状态会同时限制结果。
收藏和游玩记录会跟随账号吗？
目前记录保存在当前浏览器。要备份或换设备，在“记录、导出与离线使用”中点“备份个人记录”，到目标浏览器再用“恢复个人记录”。
为什么某个剧本没有“下载 JSON”？
部分条目只有剧照或数据不完整。可先看图片与角色名单，再尝试“复制 JSON”或转到剧本工具；使用整理出的内容前，核对作者规则和自定义角色。

把一个想法，做成可分享的剧本。

适合从零编板子、修改现有剧本，或制作角色海报。第一次尝试时，可以先加载一个官方预设，熟悉添加、移除和导出的流程。

开始编写先找创作灵感

快速体验：加载官方预设 → 添加或移除一个角色 → 生成图片 → 导出 JSON。

  1. 选择起点并填写剧本信息点击“开始编写”，填写剧本名称与作者，并按需要选择“剧本规格”。可从空白开始、使用“官方预设”，或点“导入 JSON”载入已有文件；导入时先核对预览，再确认替换当前剧本。
  2. 从角色库添加和移除角色在“角色库”中找到角色并点击添加，再次点击可移除。已选内容会出现在“我的剧本”。手机上可切换“剧本信息 / 角色库 / 我的剧本”，底部“查看剧本”便于检查当前名单。
  3. 补充自定义角色，或从图片导入点“自定义角色”填写自己的能力、类型和图标。有现成海报时，也可使用“导入剧本图片”识别角色；识别后核对名单，取消误识别、补齐遗漏，再确认导入。
  4. 整理顺序并检查搭配在“我的剧本”中调整顺序，或点“按夜序排序”。用“夜晚顺序”查看行动安排，并阅读相克 / 作者规则。随机生成可提供起点，实际搭配仍需要自己检查与试玩。
  5. 生成图片并调整排版点“生成剧本图片”（手机底部为“生成图片”），检查名称、作者、图标与能力文字。需要调整时展开高级设置中的排版、夜序、相克等选项；完成后保存 / 分享图片，或导出 PNG、SVG。
  6. 保存草稿并导出可编辑文件草稿会保存在当前浏览器，“我的草稿”可以切换剧本或保存恢复点。完成一版后点“导出 JSON”备份；之后导入这份 JSON，可继续修改，也能交给夜序查看器使用。
常见问题与操作提示
JSON 和剧本图片有什么区别？
JSON 用于再次编辑、导入其他兼容工具和查看夜序；图片用于阅读、打印与分享。建议两种都保存。普通导出 JSON 不会记录所有图片排版设置，也不能代替完整草稿备份。
为什么刷新后还有草稿，换设备却没有？
草稿存储在当前浏览器，不会自动同步到其他设备。首页“继续上次编辑”和“我的草稿”可以回到本机内容；换设备前应导出 JSON，重要版本也可在草稿里保存恢复点。
从图片识别出来的内容能直接使用吗？
请核对角色名、同名角色和遗漏项。图片导入主要恢复角色名单，特殊能力修改、作者规则和自定义夜序不会完整自动恢复；这些内容需要导入后手动补充。
图片文字放不下，或修改后导出还是旧效果？
先查看预览与排版提示，减少不必要内容、调整间距，或选择允许自动加长的版式。修改制图设置后重新生成图片，再保存 / 分享；不要用裁掉正文的图作为成品。

带团时，按夜序安排角色行动。

适合已经选好剧本、准备说书时使用。导入 JSON 后列出该剧本的首夜与其他夜晚角色行动，还可以绑定玩家，让名单更容易对照。

打开夜序查看器先找一个剧本

这里列出角色行动，不包含爪牙互认等完整夜间阶段；带团时仍需结合游戏流程。

  1. 准备并导入剧本 JSON从剧本库下载 JSON，或在剧本工具里导出。打开夜序查看器，点“选择 JSON 文件”；也可以展开“或粘贴 JSON”，粘贴文本后点“显示行动顺序”。文件在本机读取，不上传。
  2. 确认“排序依据”默认“优先使用 JSON 夜序”：明确填写的数值（包括 0）保留，未填写时补用本站数据。如果旧 JSON 的夜序全为 0，可切换“使用本站夜间行动顺序表”。有自定义夜序时先核对剧本作者的安排。
  3. 添加在场玩家并分配角色在“在场玩家”里填写名字、选择本剧本中的角色，点“添加玩家”。名字可留空，同一角色可分配给多人；夜序中会合并显示对应玩家名字。
  4. 按需要只看本局在场角色勾选“只显示在场角色的行动顺序”，过滤没有加入玩家名单的角色。先添加玩家再勾选，否则名单为空时不会显示行动。在场不等于存活，死亡角色是否行动仍应按能力判断。
  5. 对照首夜、其他夜晚并复制分别查看“首夜”和“其他夜晚”，按当前游戏进度对照角色行动。点“复制夜序”可保存为文字；开启在场过滤时，复制内容也会按当前名单过滤。
常见问题与操作提示
为什么角色没有显示夜序？
先确认它是否在导入的剧本里、是否被在场过滤排除，以及当前夜晚是否需要行动。没有夜序数据的角色可能会提示缺失；缺失数值本身不能用来判断能否行动。
刷新页面或换一个剧本后，玩家名单还在吗？
玩家名单只保留在当前页面内存中，刷新或成功导入新剧本后需要重新添加。更换板子之前，可用“复制夜序”先保存当前对照内容。
这里的操作会改变我正在编辑的剧本吗？
夜序查看器是独立工具。绑定玩家和切换排序依据不会写入剧本编辑器的草稿；需要修改角色或自定义夜序时，回到剧本工具编辑。
