夏柯怀特·Shacklewight（海外自制）

← 海外自制角色 · 恶魔 · 自制角色 · 查看语雀原文

原文更新：2025-03-08。本页保留原文规则与署名。

  • 角色类型：恶魔
  • 英文名：Shacklewight

背景故事

“我们是一条绳上的蚂蚱，对吧？”

角色能力

信源

Each night, choose any players: they all wake together. Tomorrow day, if 1 dies, they all die. Each day, if no-one dies, evil wins.

每个夜晚，你要选择任意数量玩家：他们会一起被唤醒得知此事。如果明天白天他们中有玩家被处决，所有被选择的玩家立即死亡。如果没有存活玩家被处决，邪恶阵营获胜。

角色简介

夏科怀特将所有人的性命绑在一起，同生共死。

  • 夏科怀特可以选择自己，或是邪恶玩家、死亡玩家。
  • 如果一名被夏科怀特选择的玩家被处决后没有死亡，也会触发夏科怀特的能力让所有被选择的玩家死亡。
  • 夏科怀特不能不选择任何玩家

范例

士兵67是夏科怀特，他选择了小灵，小异，小蜂，小蜜。在白天，小异被处决了，这四名玩家全部死亡。

摸鱼是水手，他在夜晚被唤醒看到小叮，小火，小船也被唤醒了。在白天小摸被处决了但是他没有死亡，而小叮，小火，小船一同死亡了。

老许是邪恶的，夏科怀特仅仅选择了他，白天没有人被处决，邪恶阵营获胜。

运作方式

  • 在首个夜晚，唤醒夏科怀特，让他指向任意名存活玩家，为他们标记“锁链”，随后让夏科怀特重新入睡，唤醒被标记“锁链”的玩家，让他们互相认识后重新入睡。
  • 如果白天处决了夏科怀特选择的玩家，宣布所有被标记“锁链”的玩家死亡。
  • 如果白天没有处决存活玩家，宣布邪恶阵营获胜。
