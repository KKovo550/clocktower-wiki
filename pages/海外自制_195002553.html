佐迪翁·Zodion（海外自制）

← 海外自制角色 · 恶魔 · 自制角色 · 查看语雀原文

原文更新：2025-03-13。本页保留原文规则与署名。

  • 角色类型：恶魔
  • 英文名：Zodion

背景故事

“他是黄道十二宫的守护者，手握魔典，掌握命运的书页。每个夜晚，他都会遵从星座的指引，带来毁灭，伤亡注定不可避免。”

角色能力

信源

​You start knowing all not-in-play characters. Each night*, the highest character on the script dies.

​在你的首个夜晚，你能查看魔典。每个夜晚*，存活玩家之中位于剧本列表最顶部一行的会死亡。

角色简介

佐迪翁将角色列当作他的杀人名单

  • 佐迪翁只有首个夜晚会被唤醒
  • 佐迪翁如果出现在剧本中，需要采用双栏排布角色列表，且横排需要对齐。
  • 佐迪翁如果出现在剧本中，剧本作者可以打乱排布规则，但是仍需按照镇民-外来者-爪牙-恶魔的方式从上至下依次进行排布。
  • 佐迪翁会从剧本列表的从上往下依次检索存活玩家，并且杀害其中位于最顶部的玩家。如果有两名玩家都位于最顶部的一行，那么他们都会死亡。

范例


运作方式

在首个夜晚，唤醒佐迪翁并对他展示魔典。他可以按照自己意愿的时长来查看魔典。

在之后的每个夜晚，找到存活玩家中位于剧本列表最顶部一行的玩家（们），在其角色标记旁放置“死亡”提示标记。

规则细节

无

与特定角色互动

莽夫：佐迪翁不直接选择玩家，因为佐迪翁可以杀死莽夫。

疯子：如果疯子认知自己是佐迪翁（不建议这么做），说书人需要在首个夜晚给他观看魔典。在之后的每个夜晚不会告知恶魔疯子佐迪翁的选择，因为他不会通过自身能力进行选择。

相克规则

罂粟种植者：如果罂粟种植者在场，佐迪翁无法查看魔典，但是在罂粟种植者死亡当晚，佐迪翁能查看魔典。

魔术师：当佐迪翁查看魔典时，爪牙和魔术师的标记会被说书人移除。

落难少女：如果佐迪翁正在场或曾经在场，落难少女中毒。

异端分子：异端分子会被佐迪翁当作一个不在场的外来者，异端分子会知道是哪个外来者。

戏子：互为克星的角色在同一时间里只能有其中一个角色在场。
