# 常见问题与排查

### 克隆 GitHub 仓库后找不到 package.json

公开仓库保存静态产物，直接打开或部署即可。开发命令需要本地完整源码项目，不能在发布目录里执行 `npm ci`。发布版 README 来自 `templates/github-readme.md`，源码说明是本文件。

### 改了文件，网站还是旧内容

先确认修改的是来源文件而非 `.astro-content/` 或 `dist/astro/` 中的生成文件。完成 `npm run validate` 后还需同步产物、推送发布仓库，并等待 Pages 部署成功。确认访问正确网址后再强制刷新；清空浏览器存储会影响草稿，不作为刷新页面的必要步骤。

### 提示无法读取旧存档或保存失败

不要立即清理浏览器数据。剧本工具仍可操作时，先点“完整备份 → 下载完整备份”，保留草稿、个人角色及版本、制图存档、方案和其中的 Logo / 背景；若完整备份失败，至少导出当前可用的剧本 JSON，再保留错误信息排查。旧存档报错时原始内容仍保留。草稿库使用 `botc_script_drafts_v1`，当前剧本兼容副本是 `botc_script_tool_v1`，自定义制图相克使用 `botc_art_custom_jinx_v1:` 前缀，必要时先在浏览器开发工具中复制相关存储再排查。

普通“导出 JSON”不包含全部制图状态，不能代替“完整备份”。恢复完整备份时，从“完整备份 → 选择完整备份”载入文件，核对预览后再恢复；恢复会替换当前剧本工具资料，开始前会自动下载恢复前备份。剧本库收藏／游玩记录和夜序对局不在剧本工具完整备份中，分别使用“备份个人记录”和“备份对局”。

### 夜序查看器刷新后是否需要重新添加玩家

自动保存成功后，玩家名单、当前夜、备注和行动进度会在同一浏览器、同一站点重新打开时恢复。请查看页面的保存状态；保存失败或另一页面更新时，先使用“备份对局”下载当前记录，不要清理站点数据。

成功导入新的剧本 JSON 或读取剧本工具当前草稿会建立新对局，不沿用原名单和进度；导入失败保留原对局。继续旧对局或换设备时，从“导入剧本与对局”选择先前下载的对局备份。“复制夜序”仅保存文本，不能作为完整对局备份。

### 夜序与预期不一致

1. 确认选中的是正确来源的角色，同名角色可能有不同 ID。
2. 在夜序窗口查看是否有手动调整；需要默认顺序时使用“恢复默认夜序”。
3. 核对总表及角色原文。待定位、表外角色使用导入值，不会被自动排入推测位置。
4. 对比导出的 `firstNight` / `otherNight`，不要用列表显示序号直接代替字段值。

### 相克规则没有显示

确认两个角色均已选中，且属于规则对应的角色版本。仅按名称匹配时，出现同名歧义会跳过规则。制图中还需开启“显示已选角色间的相克规则”。没有内置数据的组合可以添加自定义制图相克，但不会因此新增百科规则。

### 百科已有角色，为什么导入后仍无图标

制图优先复用本地图标，兼容部分不同 ID 的导入数据。若仍显示文字占位，请核对名称、角色类型及来源；同名角色有歧义时还需核对能力。未匹配到本地资源才尝试远程图片，404、网络错误或跨域限制均可能造成缺图。不要为修复图标而修改角色能力。

### PNG 没有自动下载或图标缺失

先检查浏览器下载列表与下载权限，可降低 PNG 清晰度或改用 SVG。默认复古预设使用“智能适配”，优先保留 1111 × 1500；适度调整间距后仍放不下时，按原双列分区样式自动加长。旧制图存档可能仍选择严格固定尺寸；遇到溢出提示时，点击“按原风格自动适配”或在“图片比例”中选择“智能适配”。超长 PNG 会适配设备尺寸，SVG 保留完整尺寸。远程自定义图标不保证离线可用，缺失时使用文字占位。

### 构建提示网络错误或在线编辑冲突

构建必须先读取在线编辑记录，临时错误会有限重试，仍失败则停止。恢复网络后重新运行；不要通过清空覆盖记录或关闭同步来绕过错误。若提示正文冲突，先比较本地来源与线上编辑，合并内容后再构建。后台部署与权限配置见 [后台配置说明](ADMIN.md)。

### 分享包里看不到剧本库图片

这是默认发布策略，不是资源遗漏。剧本库剧照与编辑器新生成的剧本图片是两项不同功能；前者不随默认包提供，后者可在浏览器中生成并下载。
