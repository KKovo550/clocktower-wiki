# 在线魔典

[打开在线魔典](https://kkovo550.github.io/clocktower-wiki/script_tool/在线魔典.html)

在线魔典供说书人在一台设备上管理对局。它复用本站角色、剧本和夜序资料，独立保存座位、身份、生死、投票标记、提醒、夜间进度与笔记。

## 开始一局

1. 点“选择剧本”，选择官方预设、本站剧本库的可用 JSON，或导入自己的剧本 JSON。也可读取剧本编辑器当前草稿。
2. 在“菜单”中设置 5–30 个座位，或使用右下角人数增减按钮。点圆牌分配角色，双击名称快速改名，或点“分配角色”选满人数后随机分配。
3. 单击名称打开管理菜单，记录生死、投票标记、阵营与提醒；拖动圆牌可交换座位，也可使用管理菜单中的交换按钮。
4. 进入第 1 夜后，点“夜序”记录完成、跳过或撤回；通过底部按钮推进昼夜。

配置和特殊规则由说书人决定。系统不会根据酒鬼、男爵等角色自动改变配置，也不会因死亡、中毒或醉酒自动过滤夜间行动。夜序面板默认只列已分配角色的行动，也可预览全剧本；不包含爪牙互认等完整流程。明确填写为 0 的导入夜序会保留。

“列表”适合小屏和较多人对局；“圆桌”适合查看座位关系。小屏竖屏超过 10 人、短横屏超过 8 人时默认使用列表，避免圆牌与操作入口重叠，也可从菜单手动选择布局。全屏按钮依赖浏览器支持，iPhone 上可直接使用独立界面。

界面左上角显示剧本与人数摘要，右侧提供菜单、角色表、夜序和记录，左侧可进入笔记、传奇资料与伪装。右下角控制面板支持选择剧本、分配角色、推进昼夜及增减座位，并可收起。减少已有玩家资料的末位座位时需要确认。背景资源及生成说明见[视觉资源](GRIMOIRE_ASSETS.md)。

点角色圆牌直接选择或修改该玩家角色，按镇民、外来者、爪牙、恶魔与旅行者分组，可搜索角色名称和能力。其他座位已用的角色会淡化，仍可选择以支持重复角色；当前角色有选中标记。重新选择当前角色不改动提醒，更换或清除角色会清除该玩家的提醒与私密阵营标记，保留姓名、生死与投票状态。拖动圆牌交换座位，松手后不会额外打开选角弹窗。

单击圆牌下方的玩家名称（未命名时显示座位号）打开原有管理菜单，修改状态、投票、阵营与提醒。双击名称直接打开快速改名，Enter 保存、Escape 或取消关闭；手机支持连续轻点两次。名称单击会稍等以区分双击。键盘可用 Tab 切换圆牌和名称，Enter 激活，名称上的 F2 直接改名。玩家视角下这些编辑入口均关闭。

点右侧“角色”打开分组角色面板：桌面双列展示图标、角色名与能力，小屏自动改为单列，剧本额外规则显示在顶部。说书人可淡化或隐藏尚未分配到座位的角色；“在场”按已分配角色的座位计数，包含死亡玩家，重复角色按多个座位计数。筛选只影响显示，不修改剧本和对局。玩家视角始终显示完整角色表，隐藏在场状态及筛选选项。

面板顶部“浮动”可切换为非模态窗口，拖动标题栏调整位置；标题栏获得键盘焦点时也可用方向键移动。点“固定”返回模态面板，Esc 关闭。浮动时可继续操作圆桌，打开其他工具会切换当前面板。

## 菜单与布局

右侧“菜单”按座位、剧本、说书人工具、布局、对局与备份、更多、资料导航与重新开局分组。人数可直接增减或选到指定数量；减少有资料的座位仍需确认。“打乱顺序”移动的是整位玩家，角色、提醒、生死、投票与夜间记录随玩家保留，可撤销。

布局可选标准圆形、椭圆、单列或双列垂直；显示选项只作用于本页，不改写对局存档。“在圆牌旁显示夜晚顺序”同时显示已分配角色的两种行动编号：左侧蓝色为首个夜晚，右侧红色为其他夜晚，各自与夜序面板的在场列表编号一致；该夜没有行动时不显示对应圆点。两侧编号不随当前昼夜阶段切换，死亡玩家仍保留，玩家视角隐藏这些编号。

“游戏指示”可全屏展示闭眼、睁眼、保持安静和提名提示；善良／邪恶获胜按钮只展示胜利文字，不会自动结束或重置对局。关闭展示后返回说书人。资料导航在新标签页打开，备份分组提供下载、恢复、撤销和记录；下载后菜单会提示确认文件已保存。重新开局单独放在底部，沿用确认与替换前备份流程。

## 圆牌素材、叶子与死亡帷幕

圆牌使用本地 `script_tool/theme/token1.png` 底图，角色图标略微放大，名称不论字数均沿圆牌下沿弯曲，短名称使用更紧的弧线以保持弧度。顶部绿叶数量对应角色的提示标记数量，左绿叶表示首夜行动，右绿叶表示其他夜晚行动；橙色花瓣来自角色数据中的初始设置修改标志。明确导入的 0 或 false 会保留；旧存档缺少初始设置字段时，按相同 ID 与名称查询已有角色数据。角色选择器、恶魔伪装和传奇圆牌使用同一套素材和规则。

点击座位圆牌的上方可快捷标记死亡，显示黑色帷幕；再点上方恢复存活。圆牌中央仍用于选择角色，名称仍用于玩家管理。生死操作可撤销并随备份、恢复保存，不会自动重置投票标记。死亡后圆牌右下方显示白色死亡票图标，点击淡化表示已使用，再点恢复；可投票人数同步更新。玩家视角只显示死亡票状态，不能修改。玩家视角保留公开的死亡帷幕，同时隐藏修改入口和私密角色叶子。

## 角色提示标记

鼠标进入朝桌心的下一个标记位置时才显示“＋”，移开即隐藏；悬停角色、名称或周围空白不会显示。用键盘聚焦加号时也会显示；手机和平板始终显示该入口。加号使用紫色提示标记纹理与米金色十字素材。点击后可按标记文字或来源角色名搜索，选择中毒、醉酒、善良、邪恶等通用标记，或当前剧本中的角色提示标记。“只看在场”按已分配角色筛选，包含死亡玩家。也可输入不超过 100 字的自定义标记。

添加后的紫色小圆牌使用本地 `theme/reminder1.png` 纹理，圆桌上约为角色圆牌一半大小，使用来源角色图标，与被标记玩家的角色区分；单击小圆牌即可移除，鼠标悬停可查看来源；误删可从菜单撤销。圆桌中的全部标记从各自玩家朝桌面中心依次排列，随换座、布局和窗口尺寸自动调整；悬停时的“⋯”可统一管理该玩家的标记。列表布局将全部标记放在玩家资料下方并自动换行。每位玩家最多 20 个标记。旧版文字提醒仍可使用，原有玩家管理菜单的添加与移除入口保留。

标记文字与来源随对局自动保存、备份、恢复和撤销；换座位时随玩家移动，更换玩家角色时沿用原有提醒清空规则。标记仅供说书人记录，不会自动改变生死、阵营或执行能力。玩家视角隐藏标记和全部添加／管理入口。

## 夜晚行动顺序

点右侧“夜序”打开窄版行动面板，按顺序编号、角色图标、角色名称、座位号与对应夜晚的唤醒提示排列。可随时切换“首个夜晚”“其他夜晚”，准备阶段与白天也能预览。“看全剧本”显示本剧本所有已收录的行动角色，同一角色只列一次，并标注在场座位或“不在场”；再次点击回到在场列表。在场列表中重复角色按玩家分别排列，死亡玩家仍保留并标注。夜序为 0 的角色、传奇与奇遇不列入。

只有与当前夜晚对应的在场列表显示“完成／跳过／撤回”，记录随本局保存与备份恢复。预览其他夜晚、白天或全剧本时不写记录。没有唤醒提示的角色会显示能力参考。面板右上角“浮动”允许拖动标题栏或用方向键移动，同时可操作圆桌与推进昼夜；未手动切换预览类型时，进入第 2 夜会自动切到其他夜晚。玩家视角关闭夜序并清除面板私密内容。

## 恶魔伪装与本局特殊角色

点左侧“伪装”展开三格伪装圆牌。每格可独立选择、更换或清除，选择器支持按角色名、能力搜索及镇民／外来者筛选。已分配到座位的角色自动淡化并标注“已在场”（包含死亡玩家）；“只显示不在场角色”可与搜索和类型组合筛选，开关在本次页面内切换伪装格时保留，不写入对局存档。同一角色不可占多个伪装格；若选中已分配给玩家的角色，会要求核对。清除某格保留其他格的位置。圆牌右上角的 × 可直接清除，侧边数字显示已设置数量。

“给恶魔看”会打开覆盖整个页面的纯色展示，只显示已选伪装和对应能力，不显示其他玩家身份、笔记或传奇资料。展示后将设备交回说书人，再关闭展示。

点“传奇”展开本局传奇／奇遇面板，再点 ＋ 从本站角色库或当前剧本中选择，也可创建自定义角色。自定义填写名称、类型和能力，可填写图标地址或上传不超过 1 MB 的 PNG、JPEG、WebP、GIF。点击已添加圆牌查看或编辑本局资料；右上角 × 直接移除，操作可从菜单撤销。面板显示已添加数量及当前剧本额外规则。

特殊角色只作用于本局，不会加入玩家座位、不改变存活和投票人数、不自动加入夜序，也不会改写原剧本或全站角色库。其能力与规则对玩家公开；玩家视角可只读查看，不能添加、编辑或移除。伪装始终保密。

伪装格、本局传奇／奇遇、自定义文字和上传图标随对局自动保存及备份恢复。旧版备份没有特殊角色列表时，按空列表载入。更换剧本或重新开局会清空本局设置，并按已有对局的保护流程提示和备份。

## 保存与恢复

修改自动保存到当前浏览器的 `botc_grimoire_v1`，与编辑器草稿、夜序查看器互相独立。清理网站数据、换浏览器或换设备不会自动迁移对局。

在“菜单 → 下载对局备份”导出 JSON，再从“导入对局备份”恢复。手机上请保留下载文件；iPhone 通常可在“文件”的下载目录中找到。备份包含秘密身份、伪装、提醒与笔记，应仅交给说书人。普通剧本 JSON 和对局备份使用不同导入入口。

替换已有对局时会先下载当前备份。请确认文件实际保存成功；若浏览器拦截下载，可取消操作并单独下载备份。损坏的旧存档会保留原始内容，不会被默认对局自动覆盖。出现容量不足或另一页面已更新提示时，先备份当前页面；请避免同时在多个标签页编辑同一局。

保存失败期间，页面会明确提示，并阻止网站更新按钮直接刷新。关闭页面前应导出当前对局；关闭浏览器的最终行为仍由浏览器控制。

## 玩家视角

“玩家视角”隐藏当前屏幕的已分配身份、阵营、提醒、伪装、笔记和操作工具，只保留座位、生死、投票标记、公开角色表与本局传奇／奇遇的只读展示。切换时会清除已打开弹窗和伪装面板中的私密内容。

这是展示模式，不是权限系统。拿到设备的人仍可返回说书人视角；请勿把对局备份、浏览器存档或说书人屏幕交给玩家。

## 当前范围

第一版支持单机管理和手动规则记录。尚不包含联机房间、玩家独立登录、远程发牌、语音、自动规则裁定和跨设备云同步。浏览器模拟测试不等同于 iPhone、安卓真机及长期实际对局验收。
