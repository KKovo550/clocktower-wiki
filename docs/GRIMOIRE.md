# 在线魔典

[打开在线魔典](https://kkovo550.github.io/clocktower-wiki/script_tool/在线魔典.html)

在线魔典供说书人在一台设备上管理对局。它复用本站角色、剧本和夜序资料，独立保存座位、身份、生死、投票标记、提醒、夜间进度与笔记。

## 开始一局

1. 点“选择剧本”，在“官方剧本”“剧本库”“自定义剧本”中选择；支持本站剧本库的 JSON、本地文件、JSON 地址、粘贴内容和编辑器当前草稿。
2. 在“菜单”中设置 5–30 个座位，或使用右下角人数增减按钮。点圆牌分配角色，双击名称快速改名，或点“分配角色”选择角色后随机放入座位。
3. 单击名称打开管理菜单，记录生死、投票标记、阵营与提醒；拖动圆牌可交换座位，也可使用管理菜单中的交换按钮。
4. 进入第 1 夜后，点“夜序”查看行动顺序和唤醒提示；通过底部按钮推进昼夜。

配置和特殊规则由说书人决定。系统不会根据酒鬼、男爵等角色自动改变配置，也不会因死亡、中毒或醉酒自动过滤夜间行动。夜序面板默认只列已分配角色的行动，也可预览全剧本；不包含爪牙互认等完整流程。明确填写为 0 的导入夜序会保留。

“分配角色”按类型展示圆牌，未选角色淡化，左侧显示已选数量与基础配置参考，底部显示总数。点击切换选择；开启“允许重复角色”后，已选圆牌下方显示 − 和 +，分别减少和增加数量；点击圆牌也可增加。加减按钮单独留出位置，不遮挡角色名称。选满人数时禁用加号，减号仍可使用。搜索角色名或能力、切换全角色库都保留已选内容。“清空所有角色”只清空本次选择，取消面板不会修改座位。

“全角色库”展开全部玩家角色，支持来源多选，包含官三版、华灯初上、山雨欲来、实验性、奥德赛、群星与海外自制等；“全部来源”清除来源限制，“只用本剧本”切回原范围。全库顶部的“本轮选中”集中显示已选角色与重复数量，搜索和筛选不会隐藏这份名单，点击其中的圆牌移除一张。随机补齐从当前来源范围抽取，保留此前手选的其他来源角色；搜索只影响显示。手机上来源可横向滑动，角色列表和已选预览一起滚动，底部分配按钮保持可用。

“随机角色／随机补齐”以 5–15 名非旅行者玩家的基础配置生成待分配名单，保留手动选择的角色；角色不足或已选类型超过基础配比时会提示，可继续手动选择。旅行者需先手动选入。选满后“重新随机”更换普通角色，保留旅行者。“随机分配”仅分配已选数量，未选满的座位随机留空；重新分配会确认替换全部座位的角色和提醒，保留玩家名称、生死及投票状态，可从菜单撤销。全角色库中选中的剧本外角色在确认分配时才加入本局剧本，取消或撤销都会保留原剧本。角色带有橙色花瓣时会提示核对特殊初始设置，基础配比不自动执行这些角色的能力，详见[官方设置规则](https://wiki.bloodontheclocktower.com/Setup)。

布局统一从“菜单 → 布局”切换，右上角不再单独显示“列表”按钮。手机和窄分屏触屏默认使用可滚动列表，短横屏将列表与对局控制并排；iPad 横竖屏使用更宽的圆桌和紧凑底部控制栏。自动布局随旋转、分屏恢复；手动选择的列表布局会保留。眼睛图标与右侧菜单并排，点击进入玩家视角，再点一次返回说书人；按钮的悬停提示和键盘名称会说明当前操作。

触屏的关闭和浮动按钮已扩大；输入框采用适合触屏的字号，保留浏览器缩放。软键盘弹出时，笔记、浮动窗口、计时与编辑弹窗会限制在可见区域内，内容可滚动，输入草稿不会因旋转屏幕而重建。

## 选择剧本

官方剧本使用已有预设和剧本库中的透明 logo；点击图案选择，展开简介可先阅读说明。剧本库只列实际有 JSON 的记录，支持名称、作者和分类搜索、官方／社区来源、纯官方／包含自制、分类、排序及更多结果，也可只看本浏览器剧本库里已收藏或推荐的记录。logo 优先采用剧本库分类和已保存的图片分类修正；缺少可用本地预览时使用 JSON 的 logo 元数据，再使用统一占位图。不会修改剧本库收藏或图片分类记录。

直接双击 HTML（`file://`）打开时，目录读取自动生成的 `assets/grimoire/script-directory.js`，选定剧本后按需复用剧本库已有的 `assets/data/originals/<hash>.js`，避免浏览器拦截本地 JSON 请求。通过 HTTP 打开仍读取 JSON API；两种方式使用相同原文和 logo。`scripts/prepare-api.mjs` 同时更新 API 与本地目录；修改资料后需重新生成。无需关闭浏览器安全限制。

自定义剧本支持单个或多个 JSON 文件、标准 JSON 数组，以及剧本库导出的 `[{name,json},…]` 多剧本格式。顶部显示当前使用的剧本与角色数，可快捷切换到官方剧本列表；最近导入以紧凑标签显示名称和角色数，标出当前剧本，旁边的垃圾桶只移除最近记录。手机上可滚动查看更多最近记录。

选择文件、填入示例、读取编辑器草稿和剧本工具入口集中排列；JSON 网址可按回车拉取。底部“载入剧本”始终可见，输入框支持 Ctrl／⌘ + Enter 载入；导入状态和错误也显示在底部。批量读取后先显示候选，再选择一份载入。文件总大小不超过 8 MB，多剧本包一次最多 200 份；完整自制角色、能力及明确为 0 的夜序会保留。JSON 地址支持 HTTP(S)，跨站地址需要允许浏览器跨域读取；无法读取时可先下载再选择文件。切换标签、关闭窗口、改写输入或主动载入后，旧请求不能替换当前对局。

只有确认载入的自定义剧本才进入“最近导入”，最多 10 份，单独保存在本浏览器的 `botc_grimoire_scripts_v1`；写入失败时保留本次页面里的记录并提示。删除最近记录不会删除剧本文件或当前对局。已有玩家、提醒、笔记或昼夜进度时，更换剧本仍须确认，并下载替换前备份；取消或解析失败会保留当前对局。

界面左上角显示剧本与人数摘要，右侧提供菜单、角色表、夜序和记录，左侧可进入笔记、传奇资料与伪装。右下角控制面板支持选择剧本、分配角色、推进昼夜及增减座位，并可收起。减少已有玩家资料的末位座位时需要确认。背景资源及生成说明见[视觉资源](GRIMOIRE_ASSETS.md)。

点角色圆牌直接选择或修改该玩家角色，默认只看本剧本，可切换“全部角色”。全角色模式按“本局可选”和“其他剧本的角色”分区，支持名称／能力搜索、来源（可多选）、类型和能力类别筛选；“只看本剧本”可切回。来源沿用角色百科的收录名单，包含官三版、华灯初上、山雨欲来、实验性、奥德赛、群星与海外自制。传奇与奇遇可查看，仍通过传奇面板设置，不占玩家座位。玩家卡片的角色下拉菜单也提供“全部角色…”入口，选择后返回卡片。

浏览和筛选不会修改对局。实际选择剧本外玩家角色时，只将该角色资料加入本局剧本，保留原剧本文件及已导入角色的自定义资料；角色能力、夜序和提醒随对局保存，也参与夜序显示、备份与撤销。其他座位已用的角色会淡化，仍可选择以支持重复角色；当前角色有选中标记。重新选择当前角色不改动提醒，更换或清除角色会清除该玩家的提醒与私密阵营标记，保留姓名、生死、投票状态和个人笔记。拖动圆牌交换座位，松手后不会额外打开选角弹窗。

单击圆牌下方的玩家名称（未命名时显示座位号）打开紧凑玩家卡片。顶部直接编辑名字，角色圆牌旁点击角色名称更换角色；已收录角色的“游戏建议”打开本站对应资料页。提示标记以圆牌显示，悬停或点击后使用翻转／删除按钮，“添加标记”进入统一选择器，选择后返回玩家卡片。展开“状态设置”修改生死、死亡票和私密阵营。底部可移除角色、指定另一名玩家换座或移除此座位；移除座位须确认，至少保留 5 席，可从菜单撤销。

卡片中的“笔记与行动”单独记录此玩家的私密笔记，可插入当前昼夜、标签或目标，点击“记下”保存一条记录。每条最多 2000 字、每位玩家最多 100 条，记录保留当时的昼夜；草稿随输入保存，切换标记选择器、关闭或刷新后仍保留。笔记随玩家换座，移除角色不会删除笔记，移除座位会一起移除，可从菜单撤销。全局笔记继续独立保存。

双击名称直接打开快速改名，Enter 保存、Escape 或取消关闭；手机支持连续轻点两次。名称单击会稍等以区分双击。键盘可用 Tab 切换圆牌和名称，Enter 激活，名称上的 F2 直接改名。玩家视角下这些编辑入口均关闭。

点右侧“角色”打开分组角色面板：桌面双列展示图标、角色名与能力，小屏自动改为单列，剧本额外规则显示在顶部。说书人可淡化或隐藏尚未分配到座位的角色；“在场”按已分配角色的座位计数，包含死亡玩家，重复角色按多个座位计数。筛选只影响显示，不修改剧本和对局。玩家视角始终显示完整角色表，隐藏在场状态及筛选选项。

“剧本角色”和“夜晚行动顺序”中，点击已收录角色的图标可在新窗口打开本站对应百科页；固定、浮动及手机布局均可使用。尚未收录百科页的自定义角色保留普通图标。浏览百科不会修改对局或关闭原面板。

笔记、剧本角色和行动顺序三个面板均可在顶部切换为“浮动”，拖动标题栏调整位置，拖动右下角手柄调整宽高。标题栏获得键盘焦点时，方向键移动窗口；缩放手柄获得焦点时，方向键调整宽高，按住 Shift 加快调整。尺寸会限制在屏幕范围内，窄角色表自动改为单列。同一页面内关闭再打开、切回固定再浮动都会保留调整后的尺寸。点“固定”恢复侧栏布局，Esc 关闭；三个面板可同时打开，操作圆桌不会关闭它们。

## 菜单与布局

右侧“菜单”按座位、剧本、说书人工具、布局、对局与备份、更多、资料导航与重新开局分组。人数可直接增减或选到指定数量；减少有资料的座位仍需确认。“打乱顺序”移动的是整位玩家，角色、提醒、生死、投票与夜间记录随玩家保留，可撤销。

快捷键无需组合键，不区分大小写：T 隐藏／显示已分配角色，N 推进昼夜，C 打开／收起角色列表，O 打开／收起夜晚行动顺序。N 沿用对局按钮：准备中进入第 1 夜，夜晚进入白天，白天进入下一夜；未分配完角色时仍会确认。隐藏角色后，C 显示公开角色表，N 和 O 停用。输入文字、使用输入法、长按重复、按住 Ctrl／Alt／Command 或打开弹窗／全屏展示时不会触发这些快捷键。按钮悬停提示也会显示对应按键。

布局可选标准圆形、椭圆、单列或双列垂直；显示选项只作用于本页，不改写对局存档。“在圆牌旁显示夜晚顺序”默认开启，同时显示已分配角色的两种行动编号：左侧蓝色为首个夜晚，右侧红色为其他夜晚，各自与夜序面板的在场列表编号一致；该夜没有行动时不显示对应圆点。两侧编号不随当前昼夜阶段切换，死亡玩家仍保留，玩家视角隐藏这些编号。

“游戏指示”提供 22 个常用信息标记，包括身份、在场角色、阵营、提名／投票询问和是／否。可附带最多 3 个本剧本角色（允许重复），也可输入最多 200 字的自定义文字；自定义文字留空时使用选中的信息标记。点击“展示给玩家”才会全屏覆盖魔典，只展示本次文字和附带角色；再点任意位置、按 Enter／空格或 Escape 返回准备界面，保留本次选择。角色选择器可搜索角色，并通过“返回游戏指示”返回。此功能只展示信息，不修改身份、生死或对局记录。

善良／邪恶获胜按钮只展示胜利文字，不会自动结束或重置对局。资料导航在新标签页打开，备份分组提供下载、恢复、撤销和记录；下载后菜单会提示确认文件已保存。重新开局单独放在底部，沿用确认与替换前备份流程。

## 圆牌素材、叶子与死亡帷幕

场景随对局阶段切换：准备和白天使用 `theme/bg_day.png`，夜晚使用 `theme/bg_night.png`。淡云装饰使用 `theme/clouds.png`，在座位和按钮下方，以低透明度和边缘渐隐避免干扰；夜晚更淡。恢复对局、撤销阶段切换或进入玩家视角时，背景始终对应当前阶段。

圆牌使用本地 `script_tool/theme/token1.png` 底图，角色图标略微放大。所有字数的名称沿下沿弯曲，使用黑字白色描边并略微放大字号；二字名称采用较舒展的弧线，避免过度倾斜。长名称随字数缩放，以保留完整圆牌内的边距。顶部绿叶数量对应角色的提示标记数量，左绿叶表示首夜行动，右绿叶表示其他夜晚行动；橙色花瓣来自角色数据中的初始设置修改标志。明确导入的 0 或 false 会保留；旧存档缺少初始设置字段时，按相同 ID 与名称查询已有角色数据。角色选择器、恶魔伪装和传奇圆牌使用同一套素材和规则。

点击眼睛切换玩家视角后，存活座位使用 `theme/life1.png` 的浅色兜帽问号背面；死亡且有票的座位使用 `theme/death1.png` 黑底，中央叠加直径一半的浅色背面；死亡无票则使用纯黑底。玩家视角不再叠加帷幕或外置死亡票，圆牌的无障碍名称仍说明生死与票状态。眼睛按钮变为黄色划线图标。隐藏、恢复及 Esc 返回说书人均播放约 480 毫秒的立体翻牌动画，动画背面使用相同的三种状态，不保留私密角色旧节点。连续点击以最新状态为准，系统启用减少动态效果时直接切换。该操作不写入或改变对局资料。

点击座位圆牌的上方可快捷标记死亡，黑色帷幕用约 460 毫秒从上方盖下；只有图案移动，点击区域保持原位。刷新或其他重绘不会重复播放，系统启用减少动态效果时直接显示。角色图标压暗，首夜和其他夜晚的行动顺序标记变为暗灰色；底牌、名称白边、叶子和死亡票保持清晰。再点上方恢复存活及原本的图标、蓝红顺序标记。圆牌中央仍用于选择角色，名称仍用于玩家管理。生死操作可撤销并随备份、恢复保存，不会自动重置投票标记。死亡后，白色死亡票图标紧靠编号或玩家名称右侧，统一相隔 3 像素、垂直居中，编号保持对齐圆牌中心；长名称省略显示以预留操作空间。点击票图标淡化表示已使用，再点恢复；可投票人数同步更新。圆桌和列表都沿用此布局。玩家视角可直接点击圆牌，按“存活 → 死亡有票 → 死亡无票 → 存活”循环切换。每次点击只记录一步，自动保存、同步人数，可返回说书人菜单撤销；恢复存活会恢复票，再次标记死亡时保留一张死亡票。名称点击仅显示状态，其他私密编辑入口仍隐藏。

## 角色提示标记

鼠标进入朝桌心的下一个标记位置时才显示“＋”，移开即隐藏；悬停角色、名称或周围空白不会显示。用键盘聚焦加号时也会显示；手机和平板始终显示该入口。加号使用紫色提示标记纹理与米金色十字素材。点击后可按标记文字或来源角色名搜索，选择中毒、醉酒、善良、邪恶等通用标记，或当前剧本中的角色提示标记。“只看在场”默认开启，按已分配角色筛选，包含死亡玩家；可手动关闭以查看整个剧本的提示标记。也可输入不超过 100 字的自定义标记。

添加后的紫色小圆牌使用本地 `theme/reminder1.png` 纹理，圆桌上约为角色圆牌一半大小。普通标记的文字沿底部弧线排列，保留轻微倾斜，浅金色文字搭配细暗边与很淡的光晕；角色标记使用放大的来源角色图标，文字叠在图标上方，善良／邪恶使用专用蓝／红笑脸面具。自定义标记不显示图标，短文字居中放大，长文字最多显示三行，完整内容保留在悬停提示和无障碍名称中；鼠标悬停小圆牌可查看来源并显示翻转／删除按钮；触屏先点圆牌显示操作，键盘聚焦也可使用。翻转会将圆牌内容旋转 180° 并播放动画，再点可恢复，状态自动保存；误删或误翻可从菜单撤销。圆桌中的标记以一致的边缘间距贴近角色，同一玩家的多枚标记严格沿角色到圆桌中心的直线依次增加，不再自动转向或避让；随换座、布局和窗口尺寸自动调整；悬停时的“⋯”可统一管理该玩家的标记。列表布局将全部标记放在玩家资料下方并自动换行。每位玩家最多 20 个标记。旧版文字提醒仍可使用，原有玩家管理菜单的添加与移除入口保留。

标记文字与来源随对局自动保存、备份、恢复和撤销；换座位时随玩家移动，更换玩家角色时沿用原有提醒清空规则。标记仅供说书人记录，不会自动改变生死、阵营或执行能力。玩家视角隐藏标记和全部添加／管理入口。

## 夜晚行动顺序

点右侧“夜序”打开窄版行动面板，按顺序编号、角色图标、角色名称、座位号与对应夜晚的唤醒提示排列。可随时切换“首个夜晚”“其他夜晚”，准备阶段与白天也能预览。“看全剧本”显示本剧本所有已收录的行动角色，同一角色只列一次，并标注在场座位或“不在场”；再次点击回到在场列表。在场列表中相同角色也合并为一项，列出所有对应座位，圆牌旁使用相同的行动编号。死亡玩家的座位号和单独操作会变暗；该角色所有在场玩家都死亡时，整条行动（编号、图标和提示）变暗，但保留内容供说书人判断。夜序为 0 的角色、传奇与奇遇不列入。

夜序列表始终只供查看，首夜与其他夜晚都不显示“完成／跳过／撤回”按钮。尚未分配任何角色时自动显示全剧本；清空最后一个角色后也会自动切换。预览不修改对局，旧备份中已保存的行动记录仍会保留。没有唤醒提示的角色会显示能力参考。面板右上角“浮动”允许拖动标题栏或用方向键移动，同时可操作圆桌与推进昼夜；未手动切换预览类型时，进入第 2 夜会自动切到其他夜晚。玩家视角关闭夜序并清除面板私密内容。

## 恶魔伪装与本局特殊角色

点左侧“伪装”展开三格伪装圆牌。每格可独立选择、更换或清除，选择器支持按角色名、能力搜索及镇民／外来者筛选。已分配到座位的角色自动淡化并标注“已在场”（包含死亡玩家）；“只显示不在场角色”默认开启，可与搜索和类型组合筛选；关闭后可查看自动淡化的在场角色，开关在本次页面内切换伪装格时保留，不写入对局存档。同一角色不可占多个伪装格；若选中已分配给玩家的角色，会要求核对。清除某格保留其他格的位置。圆牌右上角的 × 可直接清除，侧边数字显示已设置数量。

“给恶魔看”会打开覆盖整个页面的纯色展示，只显示已选伪装和对应能力，不显示其他玩家身份、笔记或传奇资料。展示后将设备交回说书人，再关闭展示。

点“传奇”展开本局传奇／奇遇面板，再点 ＋ 从本站角色库或当前剧本中选择，也可创建自定义角色。自定义填写名称、类型和能力，可填写图标地址或上传不超过 1 MB 的 PNG、JPEG、WebP、GIF。点击已添加圆牌查看或编辑本局资料；右上角 × 直接移除，操作可从菜单撤销。面板显示已添加数量及当前剧本额外规则。

特殊角色只作用于本局，不会加入玩家座位、不改变存活和投票人数、不自动加入夜序，也不会改写原剧本或全站角色库。其能力与规则对玩家公开；玩家视角可只读查看，不能添加、编辑或移除。伪装始终保密。

伪装格、本局传奇／奇遇、自定义文字和上传图标随对局自动保存及备份恢复。旧版备份没有特殊角色列表时，按空列表载入。更换剧本或重新开局会清空本局设置，并按已有对局的保护流程提示和备份。

## 保存与恢复

修改自动保存到当前浏览器的 `botc_grimoire_v1`，与编辑器草稿、夜序查看器互相独立。清理网站数据、换浏览器或换设备不会自动迁移对局。

在“菜单 → 下载对局备份”导出 JSON，再从“导入对局备份”恢复。手机上请保留下载文件；iPhone 通常可在“文件”的下载目录中找到。备份包含秘密身份、伪装、提醒与笔记，应仅交给说书人。普通剧本 JSON 和对局备份使用不同导入入口。

替换已有对局时会先下载当前备份。请确认文件实际保存成功；若浏览器拦截下载，可取消操作并单独下载备份。损坏的旧存档会保留原始内容，不会被默认对局自动覆盖。出现容量不足或另一页面已更新提示时，先备份当前页面；请避免同时在多个标签页编辑同一局。

保存失败期间，页面会明确提示，并阻止网站更新按钮直接刷新。关闭页面前应导出当前对局；关闭浏览器的最终行为仍由浏览器控制。

## 公聊与私聊倒计时

点左侧“传奇”下方的“计时”展开倒计时工具，再点入口或面板右上角 × 收起；收起后入口继续显示剩余时间，不会暂停计时。可切换公聊／私聊，初始分别为 5 分钟和 3 分钟，提供 1、3、5、10 分钟快捷时长，也可填写 1 秒至 180 分钟的自定义分秒。点击“开始”计时，“暂停”后可继续或修改时长，“重置”恢复当前设置的时长。运行时先暂停再切换用途或时长。

到时停在 00:00，入口显示“时间到”，面板同步变色；“到时提示音”默认开启，可关闭。收起面板、操作其他工具和切换玩家视角均不影响计时；切回后台页面时按实际经过时间更新。计时仅保留在本次页面中，刷新后重置，不写入对局存档或撤销记录。焦点在计时面板内时可用 Escape 收起。

## 全局笔记

笔记、角色表和夜序均为独立、不锁定背景的侧栏，可同时保留。记事时可操作座位、推进昼夜和切换其他工具；添加提示标记或修改角色只打开独立选择器，完成后原面板、笔记正文、筛选、滚动和浮动位置继续保留。“浮动”允许拖动标题栏，方向键也可移动；“固定”恢复侧边位置，仍可操作背景。Escape 或关闭按钮收起笔记。正文随输入自动保存，不重绘座位；面板底部显示保存状态和 8000 字上限。昼夜按钮在光标处插入当前阶段，标签与目标按钮插入可直接改写的文字；这些是记事格式，不会自动执行游戏规则。清空须确认，面板内可撤销清空，也可使用菜单撤销。原有文字笔记、对局备份和恢复继续兼容。笔记只对说书人显示，玩家视角会清空面板中的私密内容。

## 玩家视角

“玩家视角”隐藏当前屏幕的已分配身份、阵营、提醒、伪装、笔记和操作工具，只保留座位、生死、投票标记、公开角色表与本局传奇／奇遇的只读展示。切换时会清除已打开弹窗和伪装面板中的私密内容。

这是展示模式，不是权限系统。拿到设备的人仍可返回说书人视角；请勿把对局备份、浏览器存档或说书人屏幕交给玩家。

## 当前范围

第一版支持单机管理和手动规则记录。尚不包含联机房间、玩家独立登录、远程发牌、语音、自动规则裁定和跨设备云同步。浏览器模拟测试不等同于 iPhone、安卓真机及长期实际对局验收。

圆桌中央默认显示当前剧本的图标，沿用剧本库中选定的 logo，导入 JSON 时读取 `_meta.logo`；没有图标或加载失败时显示现有的“自定义剧本”骷髅蝴蝶图案。菜单“更多 → 显示剧本图标”可以关闭或重新开启，选择会单独记住，不修改对局记录。图标随剧本保存、备份和恢复，玩家视角也保留；装饰不拦截鼠标，列表布局中自动隐藏以让出资料空间。

左上角对局信息卡采用剧本图标、名称、角色类型人数与存活／投票人数的紧凑布局。类型显示“已分配／基础配置”，配置变化仍由说书人判断；超过常规人数时仅显示已分配数量。点击图标快捷打开选择剧本，右上角 « 收起为左侧“对局”按钮，再点展开，刷新后记住收起状态。收起不改变对局或关闭笔记。保存状态仍提供给辅助阅读工具，保存失败继续在警告区提示。玩家视角下隐藏分配人数，图标切换入口禁用。
