# 在线魔典

## 手机只读分享链接

在“历史／回放”打开任一阶段，点“手机只读链接”。选择阶段，先预览，确认其中的真实身份、夜间信息和提醒可以分享后，勾选确认并生成链接。默认有效期 7 天，可选 1 天或 30 天。朋友打开完整链接即可阅读，不需要登录或下载 HTML；手机可切换魔典、记录、玩家状态，按阶段阅读并点击记录定位玩家。

每条链接是生成时所选阶段的固定快照，后续修改不会同步。不含私人笔记、草稿或未选阶段，但包含所选阶段的完整身份与隐藏提醒，属于结局复盘。图标随快照嵌入，不依赖外部图床；预览会提示缺失资源。超过 8 MiB 的加密快照需减少阶段或改用互动文件。

“本机生成的分享”提供再次复制、撤销和清理过期记录。撤销凭据保存在本设备浏览器中，上传结果不明时也保留凭据；清理网站数据会丢失此设备的撤销能力，链接仍会按有效期到期。撤销阻止再次在线读取，不能收回别人已保存的内容。链接持有者都能阅读，请勿在对局中把完整身份复盘发给玩家。

分享服务必须先按 `docs/ADMIN.md` 部署，再发布对应网站资源；本地代码可用不代表线上已启用。离线互动文件与原有 PNG 导出不依赖此服务。

阅读页依次显示连接、已下载／总大小和解密整理。连接超过 15 秒、下载连续 15 秒没有新数据、总等待超过 3 分钟或解密整理超过 30 秒，会结束本次等待并恢复“重新读取”。只要仍持续下载，允许慢网络继续传输。新生成的链接会缩小背景与图标，保留角色和记录内容；已生成的旧链接保持原始数据。如果本站能打开而分享服务连接失败，请尝试切换手机流量或其他网络；仍然失败时，可让分享者改发互动文件或复盘图片。不要清除本机网站数据来处理网络连接问题，以免丢失本地对局或撤销凭据。

[打开在线魔典](https://kkovo550.github.io/clocktower-wiki/script_tool/在线魔典.html)

在线魔典供说书人在一台设备上管理对局。它复用本站角色、剧本和夜序资料，独立保存座位、身份、生死、投票标记、提醒、夜间进度与笔记。

在“菜单 → 更多 → 自定义背景”选择本地 JPG、PNG 或 WebP 图片，可预览并调整 0–75% 的背景暗度，再点“应用背景”。图片会自动缩小压缩并铺满画面，白天和夜晚共用；刷新、切换剧本或公开视图后仍保留。点“恢复默认背景”可恢复原来的昼夜场景和云雾。背景仅保存在当前设备的浏览器中，不上传，也不包含在对局备份中；上传或保存失败不会替换当前背景，关闭面板会放弃未应用的修改。复盘图片包含魔典围桌时也会沿用此背景。

“菜单 → 更多 → 网页缩放”提供 −／+ 按钮，每次调整 5%，范围 75%–150%；点击中间的百分比恢复 100%。圆牌、文字、按钮和面板一同缩放，空间不足时圆桌可滚动查看，仍支持拖动座位及浮动面板。缩放比例保存在本机浏览器，刷新后恢复，不改变对局或备份；默认 100% 沿用原布局。浏览器自带的快捷键和触屏双指缩放仍可使用。

## 开始一局

1. 点“选择剧本”，在“官方剧本”“剧本库”“自定义剧本”中选择；支持本站剧本库的 JSON、本地文件、JSON 地址、粘贴内容和编辑器当前草稿。
2. 在“菜单”中设置 5–30 个座位，或使用右下角人数增减按钮。点圆牌分配角色，双击名称快速改名，或点“分配角色”选择角色后随机放入座位。
3. 单击名称打开管理菜单，记录生死、投票标记、阵营与提醒；拖动圆牌可交换座位，也可使用管理菜单中的交换按钮。
4. 进入第 1 夜后，点“夜序”查看行动顺序和唤醒提示；通过底部按钮推进昼夜。

配置和特殊规则由说书人决定。系统不会根据酒鬼、男爵等角色自动改变配置，也不会因死亡、中毒或醉酒自动过滤夜间行动。夜序面板默认只列已分配角色的行动，也可预览全剧本；不包含爪牙互认等完整流程。明确填写为 0 的导入夜序会保留。

线下同桌开局可点“菜单 → 线下抽取角色”，或在分配角色面板点“线下抽取”。说书人先选满与座位人数相同的角色，可随机补齐、选择剧本外角色或允许重复；开始后只随机分配一次，覆盖原角色和提醒前会确认。把同一台设备按座位号依次传给玩家，玩家点“查看我的角色”，记住身份和能力后点“记住了，盖回”。盖回立即清除展示中的身份，下一位不会看到上一位的角色；按 Escape、切换页面或锁屏也会盖回，仍停留在该玩家，重新查看后盖回才计入完成。最后交还说书人确认返回魔典；提前结束也保留已分配的角色。

抽取期间魔典底层保持公开视图，展示页使用不透明背景；这是同桌轮流查看流程，不是带密码的身份验证。抽取进度保存在当前标签页的会话存储中，刷新会从盖住的当前座位继续，不重新分配；关闭标签页会结束这份进度，已分配的角色仍保存在本机对局。进度不随对局备份导出，存储失败会停止开始或推进，并提示处理。

“分配角色”按类型展示圆牌，未选角色淡化，左侧显示已选数量与基础配置参考，底部显示总数。点击切换选择；开启“允许重复角色”后，已选圆牌下方显示 − 和 +，分别减少和增加数量；点击圆牌也可增加。加减按钮单独留出位置，不遮挡角色名称。选满人数时禁用加号，减号仍可使用。搜索角色名或能力、切换全角色库都保留已选内容。“清空所有角色”只清空本次选择，取消面板不会修改座位。

“全角色库”展开全部玩家角色，支持来源多选，包含官三版、华灯初上、山雨欲来、实验性、奥德赛、群星与海外自制等；“全部来源”清除来源限制，“只用本剧本”切回原范围。全库顶部的“本轮选中”集中显示已选角色与重复数量，搜索和筛选不会隐藏这份名单，点击其中的圆牌移除一张。随机补齐从当前来源范围抽取，保留此前手选的其他来源角色；搜索只影响显示。手机上来源可横向滑动，角色列表和已选预览一起滚动，底部分配按钮保持可用。

“随机角色／随机补齐”以 5–15 名非旅行者玩家的基础配置生成待分配名单，保留手动选择的角色；角色不足或已选类型超过基础配比时会提示，可继续手动选择。旅行者需先手动选入。选满后“重新随机”更换普通角色，保留旅行者。“随机分配”仅分配已选数量，未选满的座位随机留空；重新分配会确认替换全部座位的角色和提醒，保留玩家名称、生死及投票状态，可从菜单撤销。全角色库中选中的剧本外角色在确认分配时才加入本局剧本，取消或撤销都会保留原剧本。角色带有橙色花瓣时会提示核对特殊初始设置，基础配比不自动执行这些角色的能力，详见[官方设置规则](https://wiki.bloodontheclocktower.com/Setup)。

“菜单 → 布局 → 自由摆放”允许拖动圆牌到任意位置，提示标记随座位移动；这种模式不会拖动换座或改变玩家顺序。也可聚焦圆牌后用方向键微调，Shift 加速。“重置座位位置”回到圆桌起点，仍可继续拖动。自由布局和位置按座位编号保存在当前浏览器，刷新后恢复，窗口变化时按比例适配；这些显示设置不写入对局备份。选择圆形、椭圆或列表可退出自由摆放，并保留上一次摆放位置。

布局统一从“菜单 → 布局”切换，右上角不再单独显示“列表”按钮。手机和窄分屏触屏默认使用圆桌，座位围成一圈，提示标记朝内排列，不再显示方格卡片；小屏可上下滑动；人数较多或提示标记较密时，圆桌会适当扩展，并支持横向平移。短横屏将圆桌与对局控制并排；列表仍可从菜单手动选择。手机竖屏默认在左下展示三个恶魔伪装槽，右下保留可收起的对局控制，两者并排且不遮挡圆桌；伪装面板可单独关闭，切换玩家视角会立即隐藏并清空私密内容。iPad 屏幕足够宽时使用电脑式布局：摘要在左上、工具在两侧、对局控制在右下；窄分屏自动切换为手机布局。圆牌间距和圆桌位置会随可用空间调整，避免被控制面板遮挡。自动布局随旋转、分屏恢复；手动选择的列表布局会保留。眼睛图标与右侧菜单并排，点击进入玩家视角，再点一次返回说书人；按钮的悬停提示和键盘名称会说明当前操作。

触屏的关闭和浮动按钮已扩大；输入框采用适合触屏的字号，保留浏览器缩放。软键盘弹出时，笔记、浮动窗口、计时与编辑弹窗会限制在可见区域内，内容可滚动，输入草稿不会因旋转屏幕而重建。

## 选择剧本

官方剧本使用已有预设和剧本库中的透明 logo；点击图案选择，展开简介可先阅读说明。剧本库只列实际有 JSON 的记录，支持名称、作者和分类搜索、官方／社区来源、纯官方／包含自制、分类、排序及更多结果，也可只看本浏览器剧本库里已收藏或推荐的记录。logo 优先采用剧本库分类和已保存的图片分类修正；缺少可用本地预览时使用 JSON 的 logo 元数据，再使用统一占位图。不会修改剧本库收藏或图片分类记录。

直接双击 HTML（`file://`）打开时，目录读取自动生成的 `assets/grimoire/script-directory.js`，选定剧本后按需复用剧本库已有的 `assets/data/originals/<hash>.js`，避免浏览器拦截本地 JSON 请求。通过 HTTP 打开仍读取 JSON API；两种方式使用相同原文和 logo。`scripts/prepare-api.mjs` 同时更新 API 与本地目录；修改资料后需重新生成。无需关闭浏览器安全限制。

自定义剧本支持单个或多个 JSON 文件、标准 JSON 数组，以及剧本库导出的 `[{name,json},…]` 多剧本格式。顶部显示当前使用的剧本与角色数，可快捷切换到官方剧本列表；最近导入以紧凑标签显示名称和角色数，标出当前剧本，旁边的垃圾桶只移除最近记录。手机上可滚动查看更多最近记录。

选择文件、填入示例、读取编辑器草稿和剧本工具入口集中排列；JSON 网址可按回车拉取。底部“载入剧本”始终可见，输入框支持 Ctrl／⌘ + Enter 载入；导入状态和错误也显示在底部。批量读取后先显示候选，再选择一份载入。文件总大小不超过 8 MB，多剧本包一次最多 200 份；完整自制角色、能力及明确为 0 的夜序会保留。JSON 地址支持 HTTP(S)，跨站地址需要允许浏览器跨域读取；无法读取时可先下载再选择文件。切换标签、关闭窗口、改写输入或主动载入后，旧请求不能替换当前对局。

只有确认载入的自定义剧本才进入“最近导入”，最多 10 份，单独保存在本浏览器的 `botc_grimoire_scripts_v1`；写入失败时保留本次页面里的记录并提示。删除最近记录不会删除剧本文件或当前对局。已有玩家、提醒、笔记或昼夜进度时，更换剧本仍须确认，但不再自动下载替换前备份；取消或解析失败会保留当前对局，可在菜单手动备份或撤销上一步。

菜单以分隔标题区分座位、剧本、说书人工具、布局和备份等功能；当前剧本使用独立卡片，当前布局用金色细边标识，显示设置以开关呈现。手机保留两列操作区，滚动时菜单标题和关闭按钮保持可见。

界面左上角显示剧本与人数摘要，右侧提供菜单、角色表、夜序和记录，左侧可进入笔记、传奇资料与伪装。右下角控制面板支持选择剧本、分配角色、推进昼夜及增减座位，并可收起。减少已有玩家资料的末位座位时需要确认。背景资源及生成说明见[视觉资源](GRIMOIRE_ASSETS.md)。

点角色圆牌直接选择或修改该玩家角色，默认只看本剧本，可切换“全部角色”。全角色模式按“本局可选”和“其他剧本的角色”分区，支持名称／能力搜索、来源（可多选）、类型和能力类别筛选；“只看本剧本”可切回。来源沿用角色百科的收录名单，包含官三版、华灯初上、山雨欲来、实验性、奥德赛、群星与海外自制。传奇与奇遇可查看，仍通过传奇面板设置，不占玩家座位。玩家卡片的角色下拉菜单也提供“全部角色…”入口，选择后返回卡片。

浏览和筛选不会修改对局。实际选择剧本外玩家角色时，只将该角色资料加入本局剧本，保留原剧本文件及已导入角色的自定义资料；角色能力、夜序和提醒随对局保存，也参与夜序显示、备份与撤销。其他座位已用的角色会淡化，仍可选择以支持重复角色；当前角色有选中标记。重新选择当前角色不改动提醒，更换或清除角色会清除该玩家的提醒与私密阵营标记，保留姓名、生死、投票状态和个人笔记。拖动圆牌交换座位，松手后不会额外打开选角弹窗。

单击圆牌下方的玩家名称（未命名时显示座位号）打开紧凑玩家卡片。顶部直接编辑名字，角色圆牌旁点击角色名称更换角色；已收录角色的“游戏建议”打开本站对应资料页。提示标记以圆牌显示，悬停或点击后使用翻转／删除按钮，“添加标记”进入统一选择器，选择后返回玩家卡片。展开“状态设置”修改生死、死亡票和私密阵营。底部可移除角色、指定另一名玩家换座或移除此座位；移除座位须确认，至少保留 5 席，可从菜单撤销。

卡片中的“笔记与行动”单独记录此玩家的私密笔记，可插入当前昼夜、标签或目标，点击“记下”保存一条记录。每条最多 2000 字、每位玩家最多 100 条，记录保留当时的昼夜；草稿随输入保存，切换标记选择器、关闭或刷新后仍保留。笔记随玩家换座，移除角色不会删除笔记，移除座位会一起移除，可从菜单撤销。全局笔记继续独立保存。

双击名称直接打开快速改名，Enter 保存、Escape 或取消关闭；手机支持连续轻点两次。名称单击会稍等以区分双击。键盘可用 Tab 切换圆牌和名称，Enter 激活，名称上的 F2 直接改名。玩家视角下这些编辑入口均关闭。

点右侧“角色”打开分组角色面板：桌面双列展示图标、角色名与能力，小屏自动改为单列，剧本额外规则显示在顶部。说书人可淡化或隐藏尚未分配到座位的角色；“在场”按已分配角色的座位计数，包含死亡玩家，重复角色按多个座位计数。筛选只影响显示，不修改剧本和对局。玩家视角始终显示完整角色表，隐藏在场状态及筛选选项。

“剧本角色”和“夜晚行动顺序”中，点击已收录角色的图标可在新窗口打开本站对应百科页；固定、浮动及手机布局均可使用。导入剧本的 ID 与本站不同时，会按名称和能力文本匹配唯一的已收录角色，忽略空白、全半角及常见句读差别；能力不同、匹配有歧义或尚未收录百科页时保留普通图标。浏览百科不会修改剧本能力、对局或关闭原面板。

笔记、剧本角色和行动顺序三个面板均可在顶部切换为“浮动”，拖动标题栏调整位置，拖动右下角手柄调整宽高。标题栏获得键盘焦点时，方向键移动窗口；缩放手柄获得焦点时，方向键调整宽高，按住 Shift 加快调整。尺寸会限制在屏幕范围内，窄角色表自动改为单列。同一页面内关闭再打开、切回固定再浮动都会保留调整后的尺寸。点“固定”恢复侧栏布局，Esc 关闭；三个面板可同时打开，操作圆桌不会关闭它们。

## 菜单与布局

右侧“菜单”按座位、剧本、说书人工具、布局、对局与备份、更多、资料导航与重新开局分组。人数可直接增减或选到指定数量；减少有资料的座位仍需确认。“打乱顺序”移动的是整位玩家，角色、提醒、生死、投票与夜间记录随玩家保留，可撤销。

快捷键无需组合键，不区分大小写：T 隐藏／显示已分配角色，N 推进昼夜，C 打开／收起角色列表，O 打开／收起夜晚行动顺序。N 沿用对局按钮：准备中进入第 1 夜，夜晚进入白天，白天进入下一夜；未分配完角色时仍会确认。隐藏角色后，C 显示公开角色表，N 和 O 停用。输入文字、使用输入法、长按重复、按住 Ctrl／Alt／Command 或打开弹窗／全屏展示时不会触发这些快捷键。按钮悬停提示也会显示对应按键。

“菜单 → 进入全屏”会收起菜单并请求浏览器全屏，再次打开菜单可点“退出全屏”。菜单文字跟随浏览器的实际全屏状态更新，使用浏览器自身方式退出后也会同步。若浏览器不支持或限制网页全屏，会显示对应提示；全屏切换不修改对局资料。

布局可选标准圆形、椭圆、单列或双列垂直；显示选项只作用于本页，不改写对局存档。“在圆牌旁显示夜晚顺序”默认开启，同时显示已分配角色的两种行动编号：左侧蓝色为首个夜晚，右侧红色为其他夜晚，各自与夜序面板的在场列表编号一致；该夜没有行动时不显示对应圆点。两侧编号不随当前昼夜阶段切换，死亡玩家仍保留，玩家视角隐藏这些编号。

“游戏指示”提供 22 个常用信息标记，包括身份、在场角色、阵营、提名／投票询问和是／否。可附带最多 3 个本剧本角色（允许重复），也可输入最多 200 字的自定义文字；自定义文字留空时使用选中的信息标记。点击“展示给玩家”才会全屏覆盖魔典，只展示本次文字和附带角色；再点任意位置、按 Enter／空格或 Escape 返回准备界面，保留本次选择。角色选择器可搜索角色，并通过“返回游戏指示”返回。此功能只展示信息，不修改身份、生死或对局记录。

善良／邪恶获胜按钮只展示胜利文字，不会自动结束或重置对局。资料导航在新标签页打开，备份分组提供下载、恢复、撤销和记录；下载后菜单会提示确认文件已保存。重新开局单独放在底部，确认后不会自动下载备份。

## 圆牌素材、叶子与死亡帷幕

场景随对局阶段切换：准备和白天使用 `theme/bg_day.png`，夜晚使用 `theme/bg_night.png`。淡云装饰使用 `theme/clouds.png`，在座位和按钮下方，以低透明度和边缘渐隐避免干扰；夜晚更淡。恢复对局、撤销阶段切换或进入玩家视角时，背景始终对应当前阶段。

圆牌使用本地 `script_tool/theme/token1.png` 底图，角色图标略微放大。角色名称使用微软雅黑、较轻字重和稍宽字距，沿下沿弯曲，默认黑字白色细描边；鼠标悬停圆牌或键盘聚焦时名称变白，并显示角色名称、类型与本局能力文本。移开、滚动、打开选择窗口或切换玩家视角时收起说明，玩家视角不显示私密能力。二字名称采用较舒展的弧线，避免过度倾斜。长名称随字数缩放，以保留完整圆牌内的边距。顶部绿叶数量对应角色的提示标记数量，左绿叶表示首夜行动，右绿叶表示其他夜晚行动；橙色花瓣来自角色数据中的初始设置修改标志。明确导入的 0 或 false 会保留；旧存档缺少初始设置字段时，按相同 ID 与名称查询已有角色数据。角色选择器、恶魔伪装和传奇圆牌使用同一套素材和规则。

点击眼睛切换玩家视角后，存活座位使用 `theme/life1.png` 的浅色兜帽问号背面；死亡且有票的座位使用 `theme/death1.png` 黑底，中央叠加直径一半的浅色背面；死亡无票则使用纯黑底。玩家视角不再叠加帷幕或外置死亡票，圆牌的无障碍名称仍说明生死与票状态。眼睛按钮变为黄色划线图标。隐藏、恢复及 Esc 返回说书人均播放约 480 毫秒的立体翻牌动画，动画背面使用相同的三种状态，不保留私密角色旧节点。连续点击以最新状态为准，系统启用减少动态效果时直接切换。该操作不写入或改变对局资料。

点击座位圆牌的上方可快捷标记死亡，黑色帷幕用约 460 毫秒从上方盖下；只有图案移动，点击区域保持原位。刷新或其他重绘不会重复播放，系统启用减少动态效果时直接显示。角色图标压暗，首夜和其他夜晚的行动顺序标记变为暗灰色；底牌、名称白边、叶子和死亡票保持清晰。再点上方恢复存活及原本的图标、蓝红顺序标记。圆牌中央仍用于选择角色，名称仍用于玩家管理。生死操作可撤销并随备份、恢复保存，不会自动重置投票标记。死亡后，白色死亡票图标紧靠编号或玩家名称右侧，统一相隔 3 像素、垂直居中，编号保持对齐圆牌中心；长名称省略显示以预留操作空间。点击票图标淡化表示已使用，再点恢复；可投票人数同步更新。圆桌和列表都沿用此布局。玩家视角可直接点击圆牌，按“存活 → 死亡有票 → 死亡无票 → 存活”循环切换。每次点击只记录一步，自动保存、同步人数，可返回说书人菜单撤销；恢复存活会恢复票，再次标记死亡时保留一张死亡票。名称点击仅显示状态，其他私密编辑入口仍隐藏。

## 角色提示标记

鼠标进入朝桌心的下一个标记位置时才显示“＋”，移开即隐藏；悬停角色、名称或周围空白不会显示。用键盘聚焦加号时也会显示；手机和平板始终显示该入口。加号使用紫色提示标记纹理与米金色十字素材。点击后可按标记文字或来源角色名搜索，选择中毒、醉酒、善良、邪恶等通用标记，或当前剧本中的角色提示标记。“只看在场”默认开启，按已分配角色筛选，包含死亡玩家；可手动关闭以查看整个剧本的提示标记。也可输入不超过 100 字的自定义标记。

添加后的紫色小圆牌使用本地 `theme/reminder1.png` 纹理，圆桌上约为角色圆牌一半大小。普通标记的文字沿底部弧线排列，保留轻微倾斜，浅金色文字搭配细暗边与很淡的光晕；角色标记使用放大的来源角色图标，文字叠在图标上方，善良／邪恶使用专用蓝／红笑脸面具。自定义标记不显示图标，短文字居中放大，长文字最多显示三行，完整内容保留在悬停提示和无障碍名称中；鼠标悬停小圆牌可查看来源并显示翻转／删除按钮；触屏先点圆牌显示操作，键盘聚焦也可使用。翻转会将圆牌内容旋转 180° 并播放动画，再点可恢复，状态自动保存；误删或误翻可从菜单撤销。圆桌中的标记以一致的边缘间距贴近角色，同一玩家的多枚标记严格沿角色到圆桌中心的直线依次增加，不再自动转向或避让；随换座、布局和窗口尺寸自动调整；悬停时的“⋯”可统一管理该玩家的标记。列表布局将全部标记放在玩家资料下方并自动换行。每位玩家最多 20 个标记。旧版文字提醒仍可使用，原有玩家管理菜单的添加与移除入口保留。

标记文字与来源随对局自动保存、备份、恢复和撤销；换座位时随玩家移动，更换玩家角色时沿用原有提醒清空规则。标记仅供说书人记录，不会自动改变生死、阵营或执行能力。玩家视角隐藏标记和全部添加／管理入口。

## 对局复盘

### 对局回放

点“记录 → 对局回放”，或某个昼夜下的“查看本阶段魔典”。上方选择天夜及“阶段开始／阶段结束或最新”视点；围桌复用主魔典的角色圆牌、弧形名称、死亡帷幕和紫色提醒圆牌，并根据所选阶段切换昼夜背景。提醒保留来源角色图案和翻转状态；每位玩家围桌展示前三个标记，更多标记点数量按钮或圆牌查看，玩家详情会放大展示全部标记。蓝色／红色数字表示按该阶段身份排列的首夜／其他夜晚行动顺序（旧角色资料缺少夜序时不显示数字）。点复盘记录或“定位相关玩家”会高亮行动人、目标、来源玩家及其提醒。电脑和宽屏 iPad 使用左侧魔典、右侧记录与玩家状态的布局；完整围桌自动适应剩余高度，阶段切换始终可见，记录单独滚动。手机使用“魔典／记录／玩家状态”页签；点记录定位后显示魔典，再切回记录保留原阅读位置，点圆牌进入玩家状态。可点“放大魔典”在围桌区域内滚动查看细节，再点“完整魔典”返回总览。超过 20 人时改用座位网格。回放使用独立画面，不会回退实际对局、修改角色或重新执行行动；快照代表阶段视点，不是每条记录发生的瞬间。

从本版本开始，推进昼夜和修改魔典状态时自动保留阶段快照，随对局备份保存。旧对局中途启用时标明“中途捕获”；更早阶段缺少完整快照的生死和标记显示“未记录”，不会套用最终状态。删除复盘文字阶段不会删除已经保存的实际魔典快照。玩家视角立即关闭并清空回放内容。

### 分享完整回放与阶段图片

“逐阶段长图”默认勾选所有天夜，可在预览面板选择阶段，再依次拼成一张 PNG：阶段标题 → 该阶段魔典 → 该阶段全部行动 → 下一阶段。每段魔典画面的宽高比为 6:5，保留横向围桌比例；魔典底部渐变衔接行动区，并展示阶段快照说明、图例和「本阶段行动」及记录条数。整张图片随阶段和记录数量自然延长，不裁剪内容或拆成多张图。每段固定使用该阶段结束／最新快照（不随回放当前选中的开始视点变化），角色、生死、提醒各自取当时状态；无行动的阶段仍保留魔典并显示暂无记录，缺失历史快照会注明未记录。手机分享时建议发送原图，避免聊天软件压缩文字。

在对局回放的魔典上方，可以选择“互动文件”或“阶段图片”。互动文件导出所有阶段的开始／结束快照和完整已保存记录，角色图标与背景按实际使用去重内嵌，保存为独立 HTML 文件；玩家用浏览器打开后可离线切换天夜、点记录定位、查看玩家状态和放大魔典。文件只供查看，不会导入或更改魔典存档。它包含真实身份和提醒，适合结局完整复盘，不包含全局笔记、玩家笔记或未保存草稿。某些手机聊天软件不能直接打开 HTML，可保存到文件后使用支持本地 HTML 的浏览器打开。

“阶段图片”导出按钮点击时所选阶段与视点的完整魔典及该阶段全部记录，不受滚动位置影响，也不会混入其他阶段的记录；导出标题注明阶段和开始／结束视点。旧对局缺少完整快照时明确标注生死和提醒未记录。无法内嵌的图片会在导出结果提示数量，角色名称和记录文字仍保留；完成后可点“再次保存”重新下载。关闭回放或切入玩家视角会取消尚未完成的导出。

### 状态到期提醒

添加中毒、醉酒、保护、角色标记或自定义标记时，可选择“不设期限、下个黎明、下个黄昏、指定玩家下次行动”。已有标记展开操作后，点时钟按钮设置或调整期限。

设置时限后，右下角出现“状态时限”入口；进入到期阶段后改为“待确认到期”，对应标记加金色外圈。打开列表后点“确认清除”才会移除该标记，也可调整到新的期限或改为不设期限。夜序中将指定玩家标记为“完成”会触发下次行动提醒；其他行动可在列表中点“确认该玩家已行动”。跳过行动、补写历史复盘都不会触发。时限跟随玩家永久编号，换座不影响；行动玩家已被移除时会提示重新设置。期限、到期状态和未确认标记均随对局保存，刷新不会自动清除。

能力记录使用简短的实际行动描述。失忆者可记录本局“能力是……”及“选择玩家并得知信息”；食人族可选择实际获得的能力，再记录选择玩家或“以为自己是什么角色”，例如“食人族[疯子]以为自己是方古”。“以为获得某角色能力”保留为独立选项。祖母的信息精简为“得知自己的孙子……是……”。选择目标、击杀与死亡分别记录，不从一次选择自动补出结果；此前保存的行动仍可编辑。

奥赫的“选择要杀死的角色”只选择角色；角色不在场时，可用“选择角色并记录说书人目标”填写角色和说书人决定的玩家，死亡按实际结算另记。戏法师优先提供 1／2／3 名爪牙和 1 名恶魔的猜测表单，每个位置选择不同玩家，其他人数仍可自由填写；猜测结果需要另行确认记录。提刑官分别选择本局首次提名的玩家和说书人实际告知的角色，能力规则留在提示区，保存的句子只描述获知信息。上述角色的旧行动和记录继续兼容。

当前本地角色库的 483 个玩家角色均有专属行动模板，结果补记覆盖其中 95 个角色、119 种行动。信息型角色直接填写实际收到的信息，被动或条件型能力按对应结算记录，不会为了覆盖数量而添加死亡、中毒等不适用结果。新增角色时运行 `node --test scripts/tests/grimoire-review-coverage.test.cjs`，检查角色名称、类型及完整能力定义的模板覆盖，防止只统计角色名称而遗漏版本差异。

导入剧本中的混沌同时支持“所有善良玩家中毒”和“除旅行者外的所有善良玩家中毒”两个完整能力版本，均提供夜间击杀目标和杀死邻近镇民后触发中毒的记录。按本局能力原文匹配独立模板：前者确认补记“善良阵营中毒”，后者确认补记“善良阵营非旅行者玩家中毒”。保存保留导入的角色资料，不修改当前魔典的生死或提示标记；其他改写能力仍须单独适配，不凭角色名套用模板。

战车兼容导入能力中的“该玩家死亡的”“该玩家死亡时”完整措辞，戏法师兼容“每个白天限一次，你可以公开猜测……”以及已收录剧本开头多出单引号的完整能力文字。兼容表只接纳逐条核对过的名称、类型和完整能力组合，不覆盖导入原文，也不把有不同旅行者或距离规则的旧版战车混入同一模板。战车提供当前距离中毒目标、交换角色和距离推进记录；戏法师提供逐名猜测、自由填写及实际猜测结果，明确猜对后才出现善良获胜的确认补记。

结果补记涵盖基础剧本、实验性、华灯初上、山雨欲来、奥德赛、群星和海外自制角色。投毒者、寡妇、普卡、痢蛭、战车等可补记中毒；小恶魔、珀、沙巴洛斯、刺客、教父等可补记死亡；教授与沙巴洛斯反刍可补记复活。多人目标各自确认，结果保持原目标顺序。水手、旅店老板会提供醉酒候选，确认一人后收起其他候选；普卡新目标只提示中毒，上一目标结算可分别补记死亡和恢复健康。猎手、赌徒等按所填结果决定是否提示，不从憋刀、保护、未命中或猜对推断死亡。

钦天监只填写说书人实际告知的方向，不按魔典自动推算。戏法师可先保存未判定的猜测，明确选择“猜测正确”后，才提供善良阵营获胜的确认补记。战车的中毒、角色交换分别记录；混沌击杀与“善良阵营中的非旅行者中毒”分别确认，不把旅行者算入群体效果。官方镇民公主有独立的首日提名处决与当晚不杀人记录，与海外自制的同名外来者公主分开匹配。

点一次“确认添加”才会在原行动后插入对应结果，保留原记录中的座位、姓名和角色，不改变实际生死或提示标记。确认的结果可编辑、删除、排序和撤销，刷新后不会重复提示；删除结果后可重新确认。未确认的建议不导出到复盘图片。同一阶段的手动结果最多匹配最近一次符合对象、效果及能力来源的待补记行动，不会同时消除多次行动的提示。明确确认过的结果优先按原关联处理，即使拖动到行动之前也不重复提示；醉酒候选仍按一次行动只选一人的规则收起。角色模板按完整能力定义匹配，同名但改写能力的角色不会套用结果提示。

点右侧“记录”打开黑色亚光玻璃复盘面板，按第 1 夜、第 1 天、第 2 夜等顺序记录。每阶段可“添加记录”，选择行动人（也可选说书人）、自行填写行动、勾选多个目标并补充结果；“自定义文字”适合记录公开发言、信息和其他事件。行动人预览、目标选项和保存后的记录使用“座位号＋已设置的玩家名称（角色图标＋角色名称）”，未分配角色时省略括号。已保存记录可编辑、删除，操作失误可从菜单撤销。

复盘面板顶部提供阶段选择、上一／下一阶段和“当前”定位，并可直接向所选阶段添加记录或文字。可按座位、玩家姓名、角色或正文查找历史记录；纯座位号精确匹配，多个词以空格分隔时同时匹配。查找会暂时展开匹配阶段，清除后恢复原折叠状态；搜索期间停用拖动排序；导出范围由导出面板的阶段勾选决定，不受搜索和折叠影响。各阶段可单独收起，“收起已记”折叠当前选择之外已有记录的阶段，“展开全部”恢复查看。编辑旧记录时表单就在该记录旁，添加／编辑时暂停阶段切换与列表搜索以保留当前草稿，保存后显示保存到哪个昼夜。查找和折叠仅用于当前说书人会话，切到玩家视角立即清除。

添加记录时可按座位号、姓名或角色搜索玩家，只有一个匹配结果时按 Enter 即可选中。“最近使用”可直接进入同一玩家、同一行动的填写界面；已保存记录旁的“再记一条”也提供相同入口。连续补录时点“保存并继续”，会保留记录对象和行动，清空目标、角色选项、数字和结果，防止误用上一条的信息；需要选择多个角色时，选完一个会自动切到下一个未填写的位置。保存按钮固定在编辑区底部，也可用 Ctrl／⌘ + Enter 保存，加 Shift 则保存并继续。最近使用仅在本次说书人会话内保留，切到玩家视角或清空对局后清除；原角色能力变化后，不再提供失效的能力快捷入口。

更换专属行动的记录对象时，清空原目标、角色选项、数字和能力答案，保留手写补充；若新对象没有原专属行动，会要求重新选择行动。同一对象返回再进入原行动时保留当前草稿。保存前会说明缺少的目标、角色、票数、能力来源或信息，填写完整后提示消失。每阶段 100 条、全局 2000 条的上限提前作用于新增和再记一条入口；达到上限仍可编辑已有记录。

目标玩家使用两列点选列表，可按座位号、姓名或角色搜索；纯座位号精确匹配，避免输入 1 时混入 11 号。唯一可选结果按 Enter 即可选择，已选玩家可点 × 取消。需要区分多个位置的行动会显示位置卡片，选完玩家自动切到下一个空位，也可点卡片修改某一位置。角色选择提供类型筛选和最近选择；输入搜索时同时查全角色库，精确名称优先，唯一精确匹配或唯一结果可按 Enter 选中。所有选择仍遵守该能力的角色类型、人数、自选和重复目标限制；最近角色选择不会写入对局存档，切到玩家视角后清除。

角色搜索按名称、类型和完整能力去重，忽略中文文字和标点周围的排版空格。同一角色有不同编号时优先保留本剧本的版本与图标，各个原编号仍可搜索；本剧本角色及旧记录不会因此被改写。能力或类型不同的同名角色分别保留，选项中显示来源、类型和能力摘要，存在多个精确同名结果时不会按回车自动选择。

使用中文输入法时，回车确认候选文字不会选中记录对象、目标玩家或角色，也不会触发保存；完成文字输入后，再按确认键执行选择或保存。

拖动记录左侧的手柄可调整同一天或同一夜内的顺序，电脑和触屏均可操作，靠近面板上下边缘时自动滚动。松手后自动保存；按 Esc、触摸中断或松到面板外会取消。也可聚焦手柄，用上下方向键逐条移动，Home／End 移至本阶段首尾。编辑期间暂时禁用排序；排序可从菜单撤销，备份和恢复会保留顺序。

点面板顶部“导出图片”可预览并保存 PNG 长图：上方使用当前魔典的背景与圆牌布局，保留角色图案、弧形角色名称、叶子、夜序数字、死亡帷幕、死亡票、提醒标记和中央剧本标志；裁去菜单、侧栏与操作按钮。下方按已保存的记录顺序排列，夜晚使用浅灰背景、白天使用白色背景，身份文字使用蓝红配色。可勾选要导出的昼夜阶段，选择是否包含围桌、围桌／对照中的玩家姓名及阶段变化摘要；未命名玩家显示座位号。选择部分阶段时不附加全局身份变化对照，避免混入范围之外的历史；顶部魔典若保留，始终是导出时的当前状态。记录与摘要中的姓名保留原文，这不是匿名导出。始终导出为一张完整长图，常规图片宽度为 1280 像素；内容特别长时按浏览器画布容量适当降低分辨率，保留全部记录。导出不包含操作按钮、玩家笔记和未保存草稿；记录中的历史身份与文字保持原样。图标无法载入时会提示并使用文字或占位图形。切到玩家视角会关闭预览并清除图片。

图片排版默认“舒适阅读”，正文使用 46 像素字号、宽行距和分明的昼夜标题；“紧凑长图”使用 38 像素正文并减少间距，适合记录较多的对局。魔典顶部使用实际座位位置，列表模式则整理为圆桌；圆牌下方合并显示座位号与可选姓名，底部附当前存活人数及夜序、死亡标记图例。换行会尽量保持完整角色名称、短姓名、状态词、标点、英文单词和角色图标与文字连贯，勾选的昼夜与长记录按时间顺序连续排在同一张图片中。

导出默认保留当前魔典，并提供“身份变化对照”：只列出角色、座位、姓名有变化或已离场的玩家，按同一名玩家连接起始身份、中途已记录的角色变化及导出时的身份。开始首夜时保存开局玩家与角色；尚未开始对局时首次保存复盘的快照标注“首次记录”。旧对局没有起始资料时仅使用其“最早记录”，不会推测初始身份或未记录的中途变化。全部阶段导出时，对照可单独关闭，关闭围桌仍可保留对照；部分阶段导出时该选项自动关闭并禁用，恢复全选会还原此前的选择。

每条新行动会保存当时行动人、目标和能力来源的角色名称、能力版本及图标资料，后续换角、换座、改名或修改角色库不会改写旧记录。旧备份继续可读；已缺失的历史角色资料无法从最终身份自动还原。

导出文件名过长时只缩短剧本名称，保留“复盘”和 .png 扩展名；缩短名称时不会拆开受支持的表情字符组合。

直接打开本地 HTML 时，导出会按需读取内嵌角色图标、昼夜背景、圆牌、叶子、死亡帷幕、提醒底牌和预设剧本标志，避免本地图片被浏览器跨域限制拦截。农夫、提刑官在本地 PNG 导出时优先使用 `KKovo550/clocktower-wiki` GitHub 图床中的对应图标，连接失败后使用内嵌资源；记录界面继续使用原图。在线页面优先读取原图，失败后再尝试对应的内嵌资源；自定义图片仍按其原始来源处理，不按角色名称替换。导入角色使用旧图片地址且原图不允许用于画布导出时，经过核对的完整能力版本可使用对应的内嵌图标（包括混沌、戏法师和战车的已适配版本）；同名但能力不同的未知自制角色不按名称套用其他图标。本站图床的对应图标地址也保留内嵌备用资源。更新上述魔典素材或预设标志后，运行 `node scripts/build-grimoire-review-export-assets.cjs` 刷新导出资源。

“添加游戏阶段”只扩展复盘时间线，不推进实际对局；推进游戏昼夜时会补齐对应阶段。仅末尾阶段可删除，含记录时需要确认。行动记录保留当时的座位号、姓名和角色，之后换座、换角色或移除玩家不会改写旧记录。编辑旧记录的文字时保留这些历史信息。

行动人选择“说书人”时，行动下拉增加“说书人操作”分组：告知玩家 3 个不在场角色、哪些玩家是爪牙、某个玩家是某个角色、某个角色在场，以及加入角色、假装某个角色在场、选择 1 名玩家。具体信息可在结果／补充中填写；通用行动仍可选择。改选玩家时恢复玩家的行动选项，已填写的文字和结果保留。

玩家的通用行动按提名／处决、中毒／醉酒／恢复健康／恢复清醒、死亡／不会死亡／复活、角色／阵营变化分组，另有“声称自己的角色”“获得了能力”与“自定义”。点行动输入框右侧箭头后只显示分类，各分类默认收起；点分类标题才展开具体行动，同时仅展开一个分类。选择行动后自动收起整个列表，再次打开时恢复全部收起；不再显示“其他行动”分组。输入框可用 Alt + ↓ 打开分类，分类标题支持 Enter／空格，Esc 仅关闭行动列表并保留草稿；此前保存的行动文字仍保留，也可手动填写。选择“自定义”会聚焦输入框，已有自定义文字保留，预设文字则清空供重新填写；未输入内容时不能保存。这些选项仅记录复盘，不自动执行能力或更改玩家状态。

提名／处决提供“提名玩家（记录票数）”“提名玩家（不记录票数）”“提名说书人（仅用于无神论者在场）”“投了票”以及三种处决记录（简单记录、不会死亡的简单记录、因玩家能力不会死亡）。提名玩家须选择一名目标，再选其他玩家会替换该目标；记录票数时须填写 0–999 的整数，0 票会显示并随记录保存。界面显示当前存活人数和半数供参考，不自动判断处决结果或调整投票资格。提名说书人不需要选择玩家目标，具体情况可在补充中填写。切到不记录票数的行动时不会保存隐藏的旧票数；历史记录与旧备份继续兼容。

中毒、醉酒各有“简单记录”和“因某个玩家的能力”两项；能力来源需要单独选择一位玩家，姓名、当时的角色和图标随记录显示，形成“1号因2号的能力而中毒了／醉酒了”的句子。来源与行动人一样保留历史快照，换座、换角色或删除玩家后仍可查看和编辑旧记录。恢复健康、恢复清醒可直接记录；简单记录和恢复状态不需要来源或目标，切换后不保留旧的来源信息。默认仅记录；当前阶段的新记录可明确选择“同时更新当前魔典”，增删相应中毒／醉酒标记，并可指定到期时间。

角色／阵营变化提供“角色变化”“阵营变化”“角色和阵营变化”三种方式。角色变化可按名称或能力搜索本剧本角色，也可切到全角色库；明确选择“空白”可记录为空白角色。阵营变化选择善良或邪恶，同时变化时两项都须填写。复盘会显示“现在是某角色”“现在是某阵营”或“现在是某阵营的某角色”，保留角色图标与当时的定义，刷新和再次编辑可恢复。全角色库优先沿用本剧本的同 ID 自定义定义。默认只记录历史。当前阶段新记录可选择“同时更新当前魔典”；联动换角会沿用现有换角行为，清空该玩家提醒、阵营和本夜行动进度，再应用所选的新阵营（如有）。同 ID 的不同能力版本会阻止联动，避免覆盖本局定义。

复盘随本局自动保存、备份和恢复，刷新后保留；每阶段最多 100 条、全局最多 2000 条，最多 99 天夜。保存失败会提示备份和重试。面板仅供说书人查看，切到玩家视角会立即关闭并清除已呈现的记录和未提交草稿。能力是否生效仍由说书人判断。未选择联动的记录不会改变魔典；补记过去、提前记录未来及修改已有记录始终只修订历史。原来的最近 200 项操作历史可从面板的“操作历史”或菜单的“操作记录”查看。

## 夜晚行动顺序

点右侧“夜序”打开窄版行动面板，按顺序编号、角色图标、角色名称、座位号与对应夜晚的唤醒提示排列。可随时切换“首个夜晚”“其他夜晚”，准备阶段与白天也能预览。“看全剧本”显示本剧本所有已收录的行动角色，同一角色只列一次，并标注在场座位或“不在场”；再次点击回到在场列表。在场列表中相同角色也合并为一项，列出所有对应座位，圆牌旁使用相同的行动编号。死亡玩家的座位号和单独操作会变暗；该角色所有在场玩家都死亡时，整条行动（编号、图标和提示）变暗，但保留内容供说书人判断。夜序为 0 的角色、传奇与奇遇不列入。

夜序列表始终只供查看，首夜与其他夜晚都不显示“完成／跳过／撤回”按钮。尚未分配任何角色时自动显示全剧本；清空最后一个角色后也会自动切换。预览不修改对局，旧备份中已保存的行动记录仍会保留。没有唤醒提示的角色会显示能力参考。面板右上角“浮动”允许拖动标题栏或用方向键移动，同时可操作圆桌与推进昼夜；未手动切换预览类型时，进入第 2 夜会自动切到其他夜晚。玩家视角关闭夜序并清除面板私密内容。

## 恶魔伪装与本局特殊角色

点左侧“伪装”展开三格伪装圆牌。每格可独立选择、更换或清除，选择器支持按角色名、能力搜索及镇民／外来者筛选。已分配到座位的角色自动淡化并标注“已在场”（包含死亡玩家）；“只显示不在场角色”默认开启，可与搜索和类型组合筛选；关闭后可查看自动淡化的在场角色，开关在本次页面内切换伪装格时保留，不写入对局存档。同一角色不可占多个伪装格；若选中已分配给玩家的角色，会要求核对。清除某格保留其他格的位置。圆牌右上角的 × 可直接清除，侧边数字显示已设置数量。

“给恶魔看”会打开覆盖整个页面的纯色展示，只显示已选伪装和对应能力，不显示其他玩家身份、笔记或传奇资料。展示后将设备交回说书人，再关闭展示。

点“传奇”展开本局传奇／奇遇面板，再点 ＋ 从本站角色库或当前剧本中选择，也可创建自定义角色。自定义填写名称、类型和能力，可填写图标地址或上传不超过 1 MB 的 PNG、JPEG、WebP、GIF。点击已添加圆牌查看或编辑本局资料；右上角 × 直接移除，操作可从菜单撤销。面板显示已添加数量及当前剧本额外规则。

特殊角色只作用于本局，不会加入玩家座位、不改变存活和投票人数、不自动加入夜序，也不会改写原剧本或全站角色库。其能力与规则对玩家公开；玩家视角可只读查看，不能添加、编辑或移除。伪装始终保密。

伪装格、本局传奇／奇遇、自定义文字和上传图标随对局自动保存及备份恢复。旧版备份没有特殊角色列表时，按空列表载入。更换剧本或重新开局会清空本局设置，仍会显示替换确认，不会自动下载备份。

## 保存与恢复

修改自动保存到当前浏览器的 `botc_grimoire_v1`，与编辑器草稿、夜序查看器互相独立。清理网站数据、换浏览器或换设备不会自动迁移对局。

在“菜单 → 下载对局备份”导出 JSON，再从“导入对局备份”恢复。手机上请保留下载文件；iPhone 通常可在“文件”的下载目录中找到。备份包含秘密身份、伪装、提醒与笔记，应仅交给说书人。普通剧本 JSON 和对局备份使用不同导入入口。

替换已有对局时不再自动下载备份。如需保存当前对局，可先在菜单手动下载；替换后也可从菜单撤销上一步。损坏的旧存档会保留原始内容，不会被默认对局自动覆盖。出现容量不足或另一页面已更新提示时，先备份当前页面；请避免同时在多个标签页编辑同一局。

保存失败期间，页面会明确提示，并阻止网站更新按钮直接刷新。关闭页面前应导出当前对局；关闭浏览器的最终行为仍由浏览器控制。

## 公聊与私聊倒计时

点左侧“传奇”下方的“计时”展开倒计时工具，再点入口或面板右上角 × 收起；收起后入口继续显示剩余时间，不会暂停计时。可切换公聊／私聊，初始分别为 5 分钟和 3 分钟，提供 1、3、5、10 分钟快捷时长，也可填写 1 秒至 180 分钟的自定义分秒。点击“开始”计时，“暂停”后可继续或修改时长，“重置”恢复当前设置的时长。运行时先暂停再切换用途或时长。

“中央显示倒计时”位于提示音旁，默认勾选并记住本机开关。开始后，剧本图标下方显示沙漏和分秒倒计时；收起计时面板仍继续显示，暂停时保留剩余时间并停住沙漏，时间到后变色并停止翻转。重置或重新设置时长后隐藏中央读数，待下次开始再显示。显示会随圆桌滚动和网页缩放定位；关闭剧本图标后显示在圆桌中央，不挡住角色点击。系统开启减少动态效果时沙漏保持静止，计时照常运行。

到时停在 00:00，入口显示“时间到”，面板同步变色；“到时提示音”默认开启，可关闭。收起面板、操作其他工具和切换玩家视角均不影响计时；切回后台页面时按实际经过时间更新。计时状态单独保存在当前标签页：刷新后恢复运行或暂停状态、时长、提示音和面板；运行中的计时按截止时间扣除离开期间的时间，到期停在 00:00。中央显示偏好继续单独保存。计时不写入对局存档或撤销记录。焦点在计时面板内时可用 Escape 收起。

## 全局笔记

笔记、角色表和夜序均为独立、不锁定背景的侧栏，可同时保留。记事时可操作座位、推进昼夜和切换其他工具；添加提示标记或修改角色只打开独立选择器，完成后原面板、笔记正文、筛选、滚动和浮动位置继续保留。“浮动”允许拖动标题栏，方向键也可移动；“固定”恢复侧边位置，仍可操作背景。Escape 或关闭按钮收起笔记。正文随输入自动保存，不重绘座位；面板底部显示保存状态和 8000 字上限。昼夜按钮在光标处插入当前阶段，标签与目标按钮插入可直接改写的文字；这些是记事格式，不会自动执行游戏规则。清空须确认，面板内可撤销清空，也可使用菜单撤销。原有文字笔记、对局备份和恢复继续兼容。笔记只对说书人显示，玩家视角会清空面板中的私密内容。

## 玩家视角

“玩家视角”隐藏当前屏幕的已分配身份、阵营、提醒、伪装、笔记和操作工具，只保留座位、生死、投票标记、公开角色表与本局传奇／奇遇的只读展示。切换时会清除已打开弹窗和伪装面板中的私密内容。当前标签页记住玩家视角，刷新仍保持遮盖，主动返回说书人视角后才显示身份。

这是展示模式，不是权限系统。拿到设备的人仍可返回说书人视角；请勿把对局备份、浏览器存档或说书人屏幕交给玩家。

## 当前范围

对局中的玩家使用递增且不复用的永久编号，删除后再加人、撤销和恢复同局备份不会让新人接替旧人的历史身份。旧存档载入时从现有玩家、阶段身份和复盘记录补齐编号。

推进昼夜时保存该阶段的玩家身份。补记过去阶段时，记录对象、目标和专属行动按阶段身份及已保存的角色变化读取；旧存档没有完整历史时，可以展开“校正本条记录的玩家身份”手动指定行动人的角色，只影响本条复盘。已有记录继续保留当时的身份。

未完成的复盘草稿随输入自动备份在当前标签页，刷新后打开“记录”即可继续；未保存为正式记录时，离开页面会提醒。保存或取消会清除草稿，切换到其他对局不会套用上一局的草稿。草稿备份失败时显示提示，正式存档保存失败仍保留原有警告和备份入口。

内嵌角色图标在存档和下载备份中集中保存一份，剧本、阶段身份和各条复盘只保存引用；加载时还原图标供显示和导出。旧版内嵌图标存档可直接读取，下次保存自动整理。8 MB 限制按整理后的实际备份体积计算。

第一版支持单机管理和手动规则记录。尚不包含联机房间、玩家独立登录、远程发牌、语音、自动规则裁定和跨设备云同步。浏览器模拟测试不等同于 iPhone、安卓真机及长期实际对局验收。

圆桌中央默认显示当前剧本的图标，沿用剧本库中选定的 logo，导入 JSON 时读取 `_meta.logo`；没有图标或加载失败时显示现有的“自定义剧本”骷髅蝴蝶图案。菜单“更多 → 显示剧本图标”可以关闭或重新开启，选择会单独记住，不修改对局记录。图标随剧本保存、备份和恢复，玩家视角也保留；装饰不拦截鼠标，列表布局中自动隐藏以让出资料空间。

左上角对局信息卡采用剧本图标、名称、角色类型人数与存活／投票人数的紧凑布局。类型显示“已分配／基础配置”，配置变化仍由说书人判断；超过常规人数时仅显示已分配数量。点击图标快捷打开选择剧本，右上角 « 收起为左侧“对局”按钮，再点展开，刷新后记住收起状态。收起不改变对局或关闭笔记。保存状态仍提供给辅助阅读工具，保存失败继续在警告区提示。玩家视角下隐藏分配人数，图标切换入口禁用。

魔典的普通功能面板默认使用黑色染色亚光玻璃，包括角色选择、剧本选择、自定义背景、分配角色、玩家管理，以及笔记、传奇、计时、伪装、角色表、夜序、记录和对局控制。搜索栏、卡片及筛选工具栏沿用中性黑色，边缘与高光保持柔和；后续新功能页面沿用同一默认材质。手机和平板降低模糊强度，不对模糊参数做动画；给玩家展示的信息和线下身份抽取仍完整遮盖底层魔典。

笔记、角色表、夜序和辅助面板打开时短暂淡入，关闭立即生效；按钮有轻微悬停和按下反馈。动画不改变圆桌、标记、拖动和缩放的坐标，系统开启“减少动态效果”时会停用。

新功能沿用短过渡：普通面板和剧本标签切换轻柔淡入，自定义背景更换／恢复约 300 毫秒交叉渐变，图片准备时显示加载提示；缩放、布局切换和自由摆放完成后提供轻微反馈。线下抽取的当前角色圆牌有短翻转，并显示抽取进度条；盖回、切到后台或按 Escape 仍立即清除身份，展示背景始终不透明。连续操作会替换前一段动画，系统开启减少动态效果时立即停止这些动画，设置和对局操作不受影响。

## 操作与复盘联动

进入对局后，在圆桌上修改死亡、复活或角色，会出现本次变化的记录建议。点“记录并编辑”生成带原身份的复盘条目，可继续改写结果；点“仅更新魔典”忽略建议。建议在后续操作后失效，避免把旧变化误记到新状态。圆桌修改与确认记录可一起从菜单撤销；进一步编辑文字会形成独立的撤销步骤。

记录表单的“保存范围”默认是“仅记录”。当前阶段的新死亡、复活、中毒、醉酒、恢复健康／清醒及角色／阵营变化，可以选择“同时更新当前魔典”。这会在一次提交中保存记录、更新状态和回放终点，一次撤销整体恢复。处决文字、群体行动与自定义文字仍只记录，不推断实际生效结果。

能力行动下的结果建议继续提供原有的仅补记按钮；符合条件的当前阶段个人结果，另提供“记录并更新魔典”，确认后生效。中毒与醉酒可设下个黎明、下个黄昏或该玩家下次行动后到期；到期沿用原有的说书人确认清除流程。记录会标注“曾关联魔典状态更新”，之后编辑文字不会重新执行状态变化，也不会撤回以前的状态更新。

## 阶段变化摘要

“对局回放”的记录区域显示本阶段变化摘要；互动回放文件及阶段图片也包含摘要。按永久玩家编号比较阶段开始与结束，列出死亡、复活、换角、阵营、换座、死亡票和标记变化。它描述两个端点的净变化，不能代替逐行动回放；中途变化后又恢复的内容应查看具体记录。

缺少完整快照或阶段开始是中途捕获时，明确显示无法可靠比较，不根据最终身份或行动文字推测历史。

## 对局列表、归档与恢复

打开“菜单 → 对局与备份 → 对局列表与归档”，可保存当前对局、结束并归档、下载备份、预览并恢复旧局或移出列表。列表区分未结束和已归档，显示剧本、人数、阶段与更新时间。最多保留 30 局，实际容量受浏览器存储限制；空间不足时不自动删除任何旧局。

重新开局、换剧本或恢复备份前，会先保留当前有资料的对局；无法保留时停止切换。恢复同一局的旧版本时，将正在进行的版本单独保留为一份副本。预览包含剧本、人数、阶段、更新时间和复盘条数。恢复旧版本的备份会先经现有校验与兼容处理，验证失败保持当前魔典；对局库损坏时提供原始资料下载入口。

列表与归档仍只在本设备。界面区分本地保存和本版本是否发起过备份下载；网页无法确认系统下载是否完成，需自行检查文件。归档后建议下载 JSON 备份，清理浏览器数据可能同时移除当前对局与对局库。玩家视角不显示这些私密入口。

## 选择复盘图片范围与检查清晰度

“导出图片”和回放中的“逐阶段长图”共用预览面板。默认勾选全部阶段，可逐项勾选、全选或清空；每项标明实际昼夜及记录数量。修改阶段后，旧预览和保存入口立即失效，点击“生成预览”后才能保存，避免把旧范围误发出去。其他显示选项仍会自动生成新预览。没有勾选阶段时不能生成或保存。

图片开头包含剧本名称、人数、实际所选阶段范围和记录数。可关闭“阶段变化摘要”；保留时，完整快照显示开始至结束的净变化，缺少可靠快照则明确说明，不猜测历史。“逐阶段长图”使用所选各阶段的结束／最新魔典，保留每个阶段的实际角色、生死和标记，不套用最终魔典。普通复盘图片中的顶部围桌则是导出时状态，面板会说明这一区别。

预览前显示预计像素尺寸、阶段及记录数；生成后显示实际尺寸、PNG 文件大小和图片资源加载情况。超过画布容量时仍保留一张完整图片，并提示已降低分辨率；文字可能偏小时建议减少阶段后重新生成。聊天软件可能再次压缩，建议发送原图。保存按钮位于预览上方并随滚动保持可用，不必滑到长图最底部。

范围选择与导出不会改变对局、记录顺序、搜索筛选或本地存档。预览生成过程中改动选项，会取消旧任务的展示结果；关闭弹窗或切换玩家视角同样取消任务并清理图片。
