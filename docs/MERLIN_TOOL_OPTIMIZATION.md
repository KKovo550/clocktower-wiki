# 剧本工具与制图优化记录

2026-10-02，依据源码项目内 `分析梅利剧本工具/README.md`、`docs/网站功能分析.md`、`docs/技术拆解与开发建议.md` 及公开代码快照。快照用于设计参考，不代表实时服务状态。本次沿用现有界面配色及素材系统，没有新增依赖。

## 已落实

- **导入与导出边界**：兼容外部类型、能力字段别名；保留元数据和角色附加字段，不用资料库能力覆盖导入能力。标准编辑字段在导出时更新，新增剧本清除旧元数据。
- **剧本与制图状态分离**：版式预设、一键纯净与图片能力编辑只作用于制图。夜序仍取剧本工具当前值；制图撤销不覆盖剧本夜序。
- **版式快速反馈**：舒展、固定比例、单列阅读预设作为一次可撤销操作。一键纯净隐藏素材且保留原选择，可立即恢复。
- **规则区参与布局**：海报和简洁版共用测量后的规则区。规则实际高度参与角色起始位置计算，避免长规则重叠；固定比例按原策略缩放。
- **手机操作路径**：编辑器提供三个快捷入口与角色数量；制图设置和预览分别显示，预览角色点击回到编辑区。PNG 完成后定位保存面板。
- **元数据初值**：文本版本和人数自动填入制图设置；不执行或解释外部平台布局扩展。

## 验证入口

`scripts/test-imported-rules.cjs` 覆盖规则、别名、元数据、角色扩展、实际草稿恢复与导出；`scripts/test-script-art.cjs` 覆盖长规则、两种版式及角色边界；`scripts/test-art-ui.cjs` 覆盖预设、纯净模式、撤销/重做、预览编辑与导出。完整验证使用 `npm test` 和 `npm run build`。

DOM 与画布模拟测试不替代真实 Safari、微信浏览器的触摸和文件分享验证。
