# 网站使用指南

[文档中心](README.md) · [访问网站](https://kkovo550.github.io/clocktower-wiki/)

## 工具之间接着使用

剧本库详情中，选择需要的版本后，点击「用此剧本开魔典」。新页面会预览该版本的剧本名称与角色数量，确认后开局；原有对局按魔典现有流程保护。没有 JSON 的条目暂不支持直接开局。加载期间切换剧本或版本会停止传送，需要重新点击。

- 剧本工具的「用此剧本开魔典」「独立夜序」会携带当前已编辑的角色、能力与夜序打开对应工具。
- 魔典菜单的「继续使用此剧本」可进入编辑与制图；只传送剧本定义与规则说明，不带座位身份、笔记和复盘。
- 独立夜序可用「编辑此剧本」「用此剧本开魔典」继续使用当前剧本。

接收页面会先展示剧本名称，再由你确认载入。编辑器沿用草稿保护；魔典已有对局沿用对局库保护；独立夜序替换进度前请先下载备份。各工具的修改不会自动回写，修改后可再次发送。

传送入口限同一浏览器、同一网站使用，15 分钟有效，不是对外分享链接。浏览器禁止存储、拦截新窗口或剧本超过 2 MB 时，请使用 JSON 文件导出与导入。

## 查阅角色

全站搜索可按标题、别名和正文查询，按 `/` 聚焦搜索框。全角色索引可组合筛选名称、角色类型、能力类别和来源。

全站搜索结果标明角色、剧本、规则或其他页面，可用搜索框旁的分类缩小范围。多个关键词以空格分隔时，结果需要包含全部关键词；完整名称优先于别名和正文匹配，英文搜索忽略大小写并兼容全角输入。没有正常匹配时，会给出少量近似名称供核对，不会自动替你改成另一个角色；用鼠标选择，或先按上下方向键选中，再按回车打开。

打开搜索结果后会记录本次关键词与分类，最多保留最近 8 条；仅输入而未打开结果不会记录。空搜索框获得焦点或被点击时显示最近搜索，选择记录可重新查询。“清空最近搜索”只删除搜索记录，不影响草稿或收藏。记录只保存在当前浏览器，不上传、不跨设备同步；浏览器禁止保存时仍可搜索。Escape 或点击搜索区外可关闭结果，中文输入法选字期间不会跳转。

奥德赛、群星和海外自制总览按角色类型展示图标网格，通过目录跳转到对应分类。鼠标停留在支持预览的图标上，显示中文名、已有英文名、角色类型和能力；有背景故事时在下方显示灰色斜体文字。没有收录英文名或背景故事时不会补造内容。点击图标打开完整角色页面。

同名角色可能来自不同来源，查询能力、相克和夜序时应核对来源及版本。悬浮卡片用于快速查阅，完整运作方式和规则细节在详情页。

## 手机端浏览

手机端采用较宽松的正文行距，顶部提供首页、剧本与搜索入口。点击左上角菜单按钮打开左侧抽屉，当前页面在菜单中突出显示；点击菜单链接或外侧遮罩关闭。菜单独立滚动，切换到桌面宽度时自动恢复常驻导航。支持键盘焦点循环、Escape 关闭和系统减少动态效果设置。角色总览在手机端使用两列图标排列。手机搜索会合并连续输入，中文输入完成后立即匹配；键盘弹出时结果列表按可见高度调整。输入框采用至少 16px 字号，触屏设备不加载仅供鼠标悬浮的预览脚本，并减少滚动时的动画和背景模糊。

## 导入与编辑剧本

打开[剧本工具](https://kkovo550.github.io/clocktower-wiki/script_tool/剧本工具.html)，选择角色或导入已有 JSON，填写剧本名称与作者。选择 JSON 文件后会先显示名称、作者、角色数、附加规则和缺少本地图标的提示；粘贴 JSON 后点击“预览导入”。核对后再点击“确认导入”，预览和取消不会替换当前剧本。

“我的草稿”可以打开、复制和删除草稿，或新建空白剧本。名称和角色修改自动保存；每份草稿保留最近 5 个恢复点，可手动保存恢复点，替换剧本前也会保存当前内容。恢复旧版本时保留恢复前的内容。首页会显示“继续上次编辑”入口。最多保存 50 份；需要跨设备保留完整创作资料时，请使用“完整备份”。

主剧本草稿保存角色、规则和手动夜序。制图窗口的能力修改、排版、Logo、背景等另外自动保存为对应剧本的制图存档，重新打开时尝试恢复；制图中的修改不会全部写回主剧本 JSON。留意保存提示，使用“完整备份”同时保存两类资料。制图调整栏按用途折叠分组，可搜索设置或跳转到排版、背景、夜序与 Logo 等选项。

首夜与其他夜晚可分别调整顺序，拖拽或使用调整按钮后，列表、复制文本、制图和 JSON 导出共用当前顺序。需要重来时恢复默认夜序。

“导出 JSON”用于分享角色名单和规则、导入其他兼容工具，不包含全部制图状态。换设备、换浏览器，或在直接打开 HTML 与网站之间迁移，请点“完整备份 → 下载完整备份”。文件包含全部草稿及恢复点、个人角色库和版本、制图存档、个人方案及其中的 Logo / 背景；不会自动同步到云端。

在目标浏览器打开剧本工具，点“完整备份 → 选择完整备份”，核对备份内容与当前本地资料，再点“恢复此备份”。恢复会替换上述剧本工具资料，开始前会自动下载恢复前备份。该备份不包含剧本库收藏／游玩记录或魔典对局，请分别使用剧本库的“备份个人记录”和魔典菜单的“下载对局备份”。

浏览器自动保存不能代替下载到设备上的备份。不要随意清理站点数据；出现“另一页面更新”或保存失败提示时，先下载当前资料的备份再排查，必要时先导出可用的剧本 JSON。

## 从剧本图片导入

1. 打开“从图片导入剧本”，选择 PNG、JPEG 或 WebP 图片，并选择与图片相符的排版。
2. 默认使用浏览器 PaddleOCR，无需启动额外服务。可选试验性 GPU 加速或兼容识别引擎。
3. 工具先识别标题并检索剧本库候选，核对候选的作者和版本；继续图片识别时，将识别文字与当前角色库匹配。
4. 检查识别名单，修正名称、补选遗漏角色，确认后导入编辑器，再导出 JSON。

OCR 的工作是提取文字并匹配角色库，不会从图片完整还原所有规则或自定义角色。艺术字体、同名角色、低分辨率和排版都可能影响结果；能力和默认夜序取自当前角色库，需要人工核对。

首次识别需要载入模型与运行资源，耗时与设备和网络有关；在线页面从本站下载，完整离线包从本地读取。GPU 加速不保证更快，失败时回退 CPU。关闭识别窗口可以取消当前任务，避免同时开启多个识别页面。具体引擎、缓存与兼容行为见[剧本工具说明](SCRIPT_TOOL.md#从图片导入剧本)。

## 生成剧本图片

在编辑器中打开“生成剧本图片”，默认使用“复古官方风 · 智能适配”：优先保留 1111 × 1500，先适度调整间距和行距；内容仍放不下时自动加长，宽度、双列分区、字体风格及两侧夜序保持原样。普通剧本的尺寸与布局保持原样。角色名使用实心粗宋体，正文使用 Sarasa UI SC，关键词使用真实中等字重。默认没有底部术语说明，正文利用释放的空间增加间距；需要说明时可手动选择。传奇／奇遇合并为一个分区，正文和角色图标绘制在角饰叶子上方。

可调整版式、标题、字号、背景和 Logo。“图片比例”可切换为严格的“固定参考图尺寸”，此模式仍会拒绝超限内容；选择“智能适配”或在溢出提示中点“按原风格自动适配”，即可保留当前风格并按需加长。原尺寸海报的 PNG 2 倍清晰度为 2222 × 3000；加长海报按实际尺寸导出，超长 PNG 会适配设备上限，SVG 保留完整尺寸。公开网站可上传在其他工具生成的透明 Logo；完整源码中的 AI Logo 生成仅适用于本机服务。

图片编辑支持修改角色说明、交换同类角色位置、撤销与重做，以及选择两个角色添加自定义相克。核对预览后导出完整单张 PNG 或 SVG。

图片说明、排版和自定义相克属于制图状态，不会全部写入剧本 JSON。分享成果可分别保存 JSON 和图片；保留可继续调整的制图存档、Logo 和背景时，另存“完整备份”。角色图标缺失时核对来源和角色名称；详见[故障排查](TROUBLESHOOTING.md)。

## 查看夜序

独立夜序查看器已移除。带团时在在线魔典中选择剧本、分配角色，再点击“夜序”查看行动提示。编辑剧本时仍可使用编辑器内的夜序预览。

## 用在线魔典带团与复盘

从首页的“在线魔典”进入，也可在“使用指南 → 用魔典”查看分步教程。

1. 在“选择剧本”中选择预设、剧本库条目或导入本局 JSON，设置人数，核对角色能力与夜序。
2. 点击座位名字填写玩家，点击圆牌选择角色；“分配角色”支持集中准备、随机分配和线下轮流抽取。
3. 按昼夜推进，从“夜序”查看行动，为玩家设置生死、死亡票和提醒标记。手机 15 人圆桌使用顶部快捷工具栏，小屏可滑动查看座位。
4. 点击玩家详情里的“添加复盘记录”，自动选中该玩家和当前阶段，填写目标、信息或实际结果。未匹配专用模板的能力可根据本局 JSON 生成记录表单；复杂条件保留原文，由说书人核对。默认仅记录，支持的行动可主动选择同时更新魔典，历史补记只修订记录。
5. 从“记录”查看阶段魔典，可导出图片、互动 HTML，或预览后生成手机只读链接。点击互动复盘的记录可定位相关玩家，显示的仍是阶段快照。
6. 对局资料自动保存在当前浏览器，可用对局库保存、归档或继续历史对局；换设备前用菜单下载对局备份，再到目标设备恢复。

复盘分享包含真实身份、夜间信息和提醒标记，发送前检查预览。玩家私密笔记和未保存草稿不纳入分享。只读链接是固定快照；图片、互动 HTML 和链接都不能代替可恢复整局的对局备份。

## 程序调用与反馈

开发者可通过[公共 JSON 接口](API.md)读取角色、剧本、默认夜序和相克规则，接口无需密钥，只提供读取功能。

遇到问题时，通过[GitHub Issues](https://github.com/KKovo550/clocktower-wiki/issues)提供页面地址、角色或剧本名称、复现步骤、设备和浏览器信息；规则问题附上原始来源。网站更新后可强制刷新，不必清空保存草稿的站点数据。

## 手机相册导入与图片分享

在“从图片导入剧本”中选择相册图片，可预览、每次旋转 90 度，或调整四边裁剪比例后开始识别。图片方向按浏览器的 EXIF 解码能力处理，预处理在本机完成，较大图片会缩小以控制内存。支持 PNG/JPEG/WebP；HEIC/HEIF 需要浏览器原生解码支持，不支持时请在相册转换成 JPEG/PNG。单张不超过 20 MB、3200 万像素。

上传 Logo 不超过 8 MB、1600 万像素，背景不超过 12 MB、3200 万像素。处理或导出某一图片阶段超过 30 秒会提示重试；可降低清晰度、缩小原图或下载 SVG。同一时间只进行一次 PNG 导出，关闭制图窗口会取消尚未完成的图片任务。大图编辑时撤销历史可能少于 30 步，以控制内存占用。

在剧本制图中点击“保存 / 分享”，生成 PNG 预览后可长按保存到相册、打开图片，或点击“系统分享”发送到支持的应用。系统文件分享取决于浏览器与系统支持，通常需要 HTTPS；不支持或取消分享时仍可下载 PNG。修改制图设置后等待预览更新完成，再重新保存；此前下载的图片不会自动更新。
