# 群星角色文档导入

`scripts/import_stars.py` 将《群星角色运作大合集》Word 文档按一级标题拆成角色页，保留所有非空段落、规则和署名。文档当前版本包含 34 个角色，无表格或图片。

```powershell
python scripts/import_stars.py "文档路径.docx"
npm run build
```

入口为 `pages/群星角色运作大合集.html`，详情使用 `pages/群星_角色名.html`，避免覆盖同名百科角色。全文搜索由构建自动生成。

最终角色 JSON 保存在 `config/stars.json`。运行 `python scripts/integrate_stars.py` 可重建图标、分类、导航和剧本工具配置；初次导入可以在命令后指定 JSON 文件路径。重新导入 Word 后也应运行此命令，再执行构建。图标缓存于 `assets/stars/`，已有缓存时无需联网。

最终 JSON 包含 37 个角色、38 条配置，寻宝团分线上与线下两个 ID。它提供图标、类型、能力、夜序与提示标记；Word 说明另行保留。剧本工具中搜索“群星”可找到全部配置，卡片标注群星来源，导出保留原始 ID 和远程图标 URL。群星夜序不参与官方同名角色的夜序匹配。

重新导入会替换同名群星页面；文档删除或改名的角色需要人工确认后处理旧页。导入器只适用于本合集的纯段落结构，不用于含图片或表格的其他文档。原始 Word 文件无需放入公开网站。
