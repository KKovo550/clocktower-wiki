复制 JSON

选一个范围，下面文本框里就是生成的 JSON——点「复制 JSON」直接进剪贴板 （浏览器不给剪贴板的话，文本框已经全选好，按 Ctrl+C 就行）。
1 个剧本时给的就是磁盘上那份原始 JSON，一个字都不差；多个剧本是一个 JSON 数组 [{"name":"剧本名","json":原文}]。

导出剧本

每个剧本单独一个文件夹，里面放 剧本名.json 和 剧本名-正面.xxx / 剧本名-背面.xxx。导出的内容与磁盘上的原文件 逐字节一致。
先选目标文件夹（例如 桌面\剧本json，没有就先新建一个）； 勾了「连剧本图一起」的话，会再让你选一次本剧本库内的 library/images—— 浏览器不让网页直接读磁盘，只能靠你授权那一个文件夹。
