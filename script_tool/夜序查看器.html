剧本夜序查看器

导入剧本 JSON，仅显示其中角色的首夜和其他夜晚行动顺序。文件在本机读取，不上传。

或粘贴 JSON

JSON 中明确填写的夜序（包括 0）优先保留；未填写时使用本站数据。旧 JSON 全为 0 时，可切换到本站顺序表。这里只列角色行动，不含爪牙互认等阶段步骤。

等待导入剧本。

在场玩家

    选择本剧本中的角色添加玩家。同一角色可分配给多人，夜序中合并显示玩家名字。在场不等于存活，不会自动排除死亡后仍可能行动的角色。导入新剧本会重置玩家名单。
